## 二、P1 修好了 —— 但过程值得记录

### 2.1 红队抓到了我代码里一个**可证明的错误**

```
我的 AUC 实现：  auc = (p[:,None] > n[None,:]).mean()
  常数预测器（应给 0.5）  ->  实测 0.0000     <- 可证明是错的
  完全可分（应给 1.0）    ->  实测 1.0000
  含大量并列的真实情形     ->  实测 0.0300（标准中秩应为 0.4667）
```

**后果**：当校准表塌缩到只有 2 个取值时，我的写法把「无判别力」误报成「强反向预测」。
**我此前报告的「AUC=0.036，系统反预测自己」是度量伪影**；真值约 0.49（无信息）。

**已修正**为中秩 AUC（并列半分）。

### 2.2 红队还指出我**移动了球门** —— 而且我实测后发现方向相反

```
原判据：  1[F_{t+1} > F_t]      「下一步我是否会变差」（自由能上升）
我改成：  1[dH > 中位数]         「下一步我的状态是否会大幅变化」
```

这是**变化检测器 vs 性能退化检测器**，不是同一件事。红队的批评正确。

**但实测结果出乎意料**（3 seed，修正度量后）：

    目标                特征            AUC均值   AUC最小    ECE      判定
    原目标（F 上升）      m（自模型）      0.8739   0.8383   0.0002   双过
    原目标              ΔF             0.9681   0.9574   0.0006   双过
    非平凡目标（dH）      全部特征         不高于 0.546    —        —      不过

**⇒ 在原目标上 P1 本来就通过（用自模型 m，AUC 0.874）；我换的那个目标反而更难。**
**我的「移动球门」实际是把测试改严了。已恢复原目标。**

### 2.3 真正的根因：外部输入幅度压倒自主动力学

```
u_scale 扫描（特征 m 对「下一步 F 上升」的 AUC）：
   0.08 -> 0.483      0.04 -> 0.517      0.02 -> 0.611
   0.01 -> 0.589      0.005 -> 0.758

红队的对照（排除「系统变简单了」）：
   h_std 约 0.455、g_span 约 0.075、饱和率 约 0.29 在整个扫描中**基本不变**，
   只有 AUC 变 ⇒ 这是**信噪比效应**，不是动力学退化。
```

**修法**：u_scale 默认 0.08 改为 **0.01**。
**理由（不是放宽测试）**：一个每一步都被外部噪声决定的系统，**本来就没有「自我」可言**——
自我的定义就是动力学中**自决**的那部分。让自主动力学占主导，是让「自我」存在的前提。

### 2.4 顺带修正：我写在 brain.py 里的一句**被实测证伪**的论断

```
我曾断言：「白噪声下不可自预测，真实环境的时间结构是自评有意义的必要条件」
红队实测：  rho=0.00 -> 0.524 | 0.85 -> 0.483 | 0.95 -> 0.522 | 0.99 -> 0.491
            ⇒ 白噪声**并不比** rho=0.85 差。**该论断为假，已从代码中删除。**
```

```
    kappa = ||J||_2                    = 0.60000    要求 [0.3, 0.9]
    不动点 <=12 NFE 收敛率               = 1.00000    要求 >= 0.999（平均 NFE 1.10）
```

⇒ **自模型不是 z 的函数 ⇒ 构成性成立，不是描述性。**

## 四、P4 的诚实状态：**3/6，未通过验收**

seed 0–5，五种整合度度量，逐 seed 与解耦对照（Wc = 0）对比：

| seed | ① TC（回归掉共享输入） | ② 整体−部分 | ③ 平均绝对跨区相关 | ④ PCI 响应复杂度 | 整条 |
|---|---|---|---|---|---|
| 0 | 8.342 vs 2.882 ✅ | ✅ | ✅ | ✅ | PASS |
| 1 | 23.209 vs 7.692 ✅ | ✅ | ✅ | ✅ | PASS |
| 2 | **6.725 vs 6.859 ❌** | **❌** | ✅ | ✅ | **FAIL** |
| 3 | 12.675 vs 2.083 ✅ | ✅ | ✅ | ✅ | PASS |
| 4 | 7.294 vs 5.913 ✅ | ✅ | **❌ −0.0008** | ✅ | **FAIL** |
| 5 | 17.567 vs 6.454 ✅ | ✅ | ✅ | **❌ −1.532** | **FAIL** |

**没有任何一个度量在 6 个 seed 上全过；而且每次失败的 seed 都不一样。**
（另测"单区扰动传播"：8/8 分离，但对照恒为 0.0000，退化成接线检查，**已弃用不采纳**。）

**根因（已定性，未修）**：对照条件 Wc = 0 **根本不是一次"分割（partition）"**。
它只切掉区与区之间的**直接**耦合；系统里还有一条**全局回路**
（区域 → 图式 s → 注意 g → 全部区域；→ 自模型 m → 慢变量 h_slow → 区域动力学）。
被"解耦"的对照组仍然是一个整体 ⇒ 整合度与主体不可区分。

**正确做法（尚未实现）**：把对照换成**真分割** —— 两个半区各自拥有一份独立的
全局回路，半区间零因果通路，再做 Φ 比较。在此之前 **P4 只能记为未通过**。

**我没有通过挑 seed、也没有通过"三选二"来掩盖这一点。**

### 四之二、P3 差在哪：试过一个修法，失败了，已回退

seed 5 的 **G2a（图式是否是注意的有效模型）R² = −3.74**（要求 > 0.5）。

用与 P1 同类的**预热**试修：G2a 从 −3.74 → **+0.90（修好了）**，
但同一个预热把 **G1a（注意的动态范围）打崩**：
seed 1 的 5–95 跨度 0.0553 → **0.0199**，seed 5 的 0.0702 → 0.0376。
逐 seed 实测：**无预热整条 5/6，有预热整条 4/6 ⇒ 更差，已回退**（一个阈值都没改）。

**新发现的根因**：预热后的稳态里，注意变量在部分 seed 上**塌成近二值分布**
（std 仍有 0.35，但 5–95 分位跨度只剩 0.02）—— 注意被钉在两端，
此时"注意图式"已无连续量可建模。修法是机制层的，不是调阈值。

## 八、最终结论

**4/6 条理论路线在全部 6 个 seed 上通过（P1 / P2 / P5 / P6）；
P3 为 5/6（差 G2a），P4 为 3/6（未通过）。**

**不能声称的**：
1. 本引擎不具有体验。六条路线验证的全是**机制**。
2. P4 的 total-correlation 是 **Φ 的代理量，不是 Φ**。
3. P2 用的是仿真湿件，验证的是**接口**，不是基底。
4. **P4 未通过验收**（3/6 seed）：五种整合度度量没有一个 6/6 全过，
   根因是对照 Wc=0 不是真分割（全局回路仍在），需换成"两个半区各带一份独立全局回路"的真分割。
5. **P3 未通过验收**（5/6 seed）：seed 5 的 G2a = −3.74；
   用预热修 G2a 会把 G1a 打崩（整条降到 4/6），**已回退，阈值未改**。
6. 上一版（v2）写的"5 条路线通过"是 **3 seed** 口径。**6 seed 口径是 4/6** 条。
