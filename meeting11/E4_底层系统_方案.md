## 1. 诊断：当前 AHI 的"Transformer 式"病，从执行层看是什么

### 1.1 一句话病根

所有者说病根是"统计修补堆叠"。在执行层，这句话有一个精确的工程同义词：
**整个系统是同一个 Python 进程里同一个 for 循环上叠出来的读出层栈——没有时间，只有步数。**
Transformer 式思维的工程本质是"一切靠窗口统计量说话，窗口之外无实在"；
AHI 现状是它的离散时间版：窗长=20 个探测、稳定步=10 个探测、τ 用 T=8000 样本的窗口拟合、
采样率="1kHz"是字符串——**没有一个判据知道自己活在几毫秒里。**

### 1.2 六条工程病（逐条引代码，全部静态审计）

**病 1 · 时间是装饰品。**
`ahi_theory/mbp.py` L112 `采样率: str = "1kHz"`、L116 `延迟: str = "1ms"`——
描述符里唯二与实时性相关的字段是**两个字符串**，全仓库**无任何消费者**。
`MBP总线.t` 是逻辑步数计数器（L316、L395-405 `步进()`），不是时间。
系统不知道自己跑多快，也不知道任何一次交互花了多久。

**病 2 · 上帝时钟与上帝循环。**
`mbp.步进()`（L395-405）一个循环推进一切：总线时钟、所有模块心跳。
`selfprobe.步进()`（selfprobe.py L236-258）再叠一层：对每个在线模块顺序探测。
meeting10 G1 实证了这种紧耦合的必然后果：`modality.在线学文本投影` 内含 `总线.步进(1)`，
与闭环同用 ⇒ bus.t 每拍 +2（双时钟推进）——**不是 bug，是"只有一个时钟"这个设计的必然产物**：
谁想动一下时间，就得偷上帝的表。G2（`读()` 有副作用：EMA 推进/事件出队/序列号++，
同拍双消费者互偷）同根。

**病 3 · 零延迟同进程世界："非我"的物理基础被删除了。**
`world.响应(指令向量)`（world.py L103-105）在调用线程内同步推进并返回；
CMD→RESP **同拍、零传输延迟、零采样延迟**。`世界模块` 是同进程对象，
`世界.感知()` 返回 `self.状态.copy()`——读它就像读自己的一个字段。
**真实世界的"非我"感有一半来自延迟结构的不对称**：我动我的身体，后果紧跟且形状可学；
世界动，是它自己的时钟在动，与我的探测节奏无关。当前实现把这两种情况
做成了同一种东西——同一线程里的同步函数调用。归因问题被人为简化了，
S 组 30/30 的漂亮分数有多少是这个零延迟共谋送的，无人知道。

**病 4 · 世界的"自主时钟"是假的。**
`selfprobe.外生世界模块.响应()`（selfprobe.py L134-137）：世界"以自主时钟前进一步"——
但推进只发生在**被探测时**（`世界.步(None)` 在 `响应()` 里被调）。
外生世界的时间自主性 = "我戳它一下它才走一步"。G4（world 唯一推进器=`响应()`，
多写者即双重演化）是同一事实的另一面。§6.1 条件 1"独立"只做到了**结构性独立**
（无动作输入），**时间性独立为零**——一个只在被观测时演化的世界，
在物理上与"我的回声"不可区分，这不是判据能救的，是本体构造错了。

**病 5 · 判定无时间预算，补丁打在步数轴上。**
`selfprobe.py` L108-114：窗长=20、稳定步=10，单位是**探测数**。两个直接后果：
① meeting10 P2：事件稀疏模块 2000 步只来 4-6 个事件，窗永不满 ⇒ 永远 unknown——
窗在时间上不闭合，状态机在时间上冻结；
② meeting10 P1：d=16 欠定段 17 个伪样本击穿 d=8 时代的结构性论证，修复（修法①②）
是把"探测数 ≥ (ma+1)+窗长""复核长窗=100 拍"继续打在**探测数轴**上。
每补一次，参数与宽度的耦合面就大一圈（窗长、稳定步、复核步、复核长窗、ma 全部纠缠）。
根因不是参数没调好，是**这根轴从头就不该是"探测数"**——归因是时间预算内要交卷的任务，
"unknown 但带置信随时间上升"才是活系统的行为，"窗不满就永远不出结果"是脚本的行为。

**病 6 · "不倒"从未被测试过，因为系统不被允许倒。**
- 心跳不可失败：`mbp.步进()` 里在线模块的心跳由总线**代发**（L399-402）。
  真看门狗的语义是"被监控者必须自己来喂，没来喂就超时"；这里的狗是自己喂自己，
  它唯一能测到的是显式置的 `在线=False` 标志。挂起时延=超时 3+1 拍（INT §0 实测）——
  测的是标志位，不是存活性。
- 调用无截止：`mbp.写()` L488 `w = rec.设备.响应(a)` 是裸函数调用——
  任何一个设备死循环 = 内核死循环。**没有任何一条路径有超时**。
  `selfprobe` 的 try/except 异常隔离（L256-258）只隔离"抛异常"，不隔离"不返回"。
- 时间无界操作混在主循环：`modality.慢特征投影器.重构()` 每 200 步做 7 次
  `np.linalg.eigh`（64×64）+ 在线响应模型的最小二乘反演——若真按描述符跑 1kHz，
  这是在实时路径里埋了无上界的阻塞调用。仿真里没炸，只是因为仿真没有截止时间可违反。
- 内存无界：`selfprobe._证据.事件流`（L338）与 `mbp._记录.探测记录`（L493）是裸 list，
  只增不减。2000 步没事；"全自主长期运行"是另一个量级的承诺。

**总评**：这六条不是实现瑕疵，是范式。统计窗替代了时间预算（病 1/5），
单循环替代了调度（病 2），同步调用替代了物理延迟结构（病 3/4），
永不出错的仿真替代了可失败的系统（病 6）。
**这就是"Transformer 式"在执行层的长相：所有困难都被关进了窗口统计的舒适区，
而全自主恰恰住在窗口外面。**

## 2. 核心主张

**一句话：自主性首先是"不倒"——把 AHI 从单时钟单循环的仿真脚本，重构为三个时钟域独立、
预算独立、越级抑制与释放明确的分层执行栈（反射环/行为环/慢思考环），
层间只以带时间戳的异步消息相遇；每一层的存活由可失败的时序合同（节拍抖动、看门狗、
降级演练、延迟注入）来验收，而不是由"跑完 2000 步没炸"来默许。**

**为什么它天生"全自主"（不靠外部标注/奖励/拟合）：**
1. "不倒"的定义是系统**自己**的时序合同：我的节拍、我的截止、我的看门狗、
   我的降级阶梯。验收手段是故障注入（杀层、注入延迟、超载），**零外部标签、零拟合**——
   与 P1-P8 用统计量表量化自我的路线在方法论上正交。
2. "非我"判别获得**真实的物理基础**：世界拥有独立时钟域（不再被我戳一下走一步），
   身体通路与世界通路的延迟结构天然不对称（我方 CMD 的 RESP 延迟短且可学，
   外生事件的时相与我的探测节奏无关）。归因状态机吃的证据从"同进程零延迟共谋"
   变成"时钟域与延迟的可测差异"——这是结构给的白送的、不用拟合的不对称性。
3. 分层本身就内置了发展阶梯的最底层：反射先于行为先于思考，
   上层死了下层还在——这正是"婴儿先有脊髓反射后有认知"的机器版
   （发展叙事归 E2，我只提供这个阶梯的工程骨架）。

## 3. 机制

### 3.1 三环架构与分层延迟预算

仿生对应（只作结构类比，不谈认知）：脊髓反射环 → 脑干/感觉运动环 → 皮层慢环。
三环各自独立时钟、独立预算、独立看门狗，**任何两环之间不存在同步函数调用**。

| 环 | 周期 | WCET 预算 | 职责 | 死亡后果 |
|---|---|---|---|---|
| **R0 反射环** | 1 ms（本阶段软实时起步，见 §6） | ≤0.3 ms/拍 | 安全钳制（限幅/急停/包络）、包龄期巡检（过期 SENSE/CMD → 置信降级）、喂狗者 | **唯一致命层**。必须简单到可静态审计：无内存分配、无特征分解、无 IO |
| **R1 行为环** | 20 ms（50 Hz） | ≤8 ms/拍 | MBP 探测循环（selfprobe 挂此）、感觉运动协调、世界读写、归因状态机在线部分、行为动作 | 退化为"脊髓态"：安全姿态维持、反射仍活；探测/归因/行为停摆 |
| **R2 慢思考环** | 200 ms–2 s，周期+事件驱动 | 无硬截止；产出有**龄期上限**（默认 5 s，过期不被消费） | brain RNN 内核多步动力学、φ 重构（eigh）、响应模型反演、学习/巩固（接口留给 E1）、归因复核 | 系统变笨但活着：停止学习与归因更新，R1 冻结最后置信继续运行 |

核心不变量：**R0 不依赖 R1/R2 的任何输出即可维持安全态；R1 不依赖 R2 的新鲜输出即可继续探测**
（用最后有效门控参数，龄期超标则回退默认门控）。这就是"脊髓不死"的机器版。

### 3.2 消息与时间戳：把 MBP 包升级为定时包

沿用 MBP包 的好资产（九字段、载荷哈希校验、单调序列号、降级包约定、B9 档案），
纯追加四个字段（**不改既有字段语义**，避免破坏已登记口径）：

```
定时包(MBP包) +:
    时钟域: str        # "R0" | "R1" | "R2" | "world" —— 声明时间戳属于哪个时钟
    单调时间戳: float  # 该时钟域内的单调时钟读数（ns），替代/并列现有逻辑 时间戳
    龄期上限: float    # 消费侧超过则按降级包处理（置信=0），复用现有降级语义
    传输延迟: float    # 描述符.延迟 从字符串变数值，写入包；消费侧做延迟补偿
```

- **单写者纪律（G4 的推广成体系）**：每个主题（模块ID, 包类型）恰一个写者环；
  写者只写自己的环队列，读者从队列取。
- **读无副作用（修 G2/G1 的根）**：设备由自己时钟域的节拍推进，
  `读()` 退化为"取最新快照"（双缓冲/seqlock 语义），EMA、事件出队等设备内部状态
  只被设备自己的节拍触碰。`步进()` 上帝循环废除——**没有总线步进，只有各环各自的 tick**。
- **龄期与延迟补偿（控制论最小件）**：消费侧检查 `单调时间戳 + 传输延迟` 的龄期；
  对已知回路的固定延迟做一步前馈补偿（Smith 预估器的退化形式），补偿不了的靠
  置信字段降级——**置信从装饰变成真正承载"数据多旧"的量**。

### 3.3 越级抑制与释放（supervisory gating）

上层永远**不直接下命令**，只下发门控参数包 `(门控 g∈[0,1]^d, 参数序列号, 龄期)`：

- R2 → R1：门控/偏置/仲裁参数（例如行为幅度包络、归因复核建议）。
  R1 只消费**最新且未过期**的参数包；R2 死了或超龄 ⇒ R1 用内置默认门控继续。
- R1 → R0：R1 的输出必须落在 R0 维护的**安全包络**内（限幅是硬的）。
- **R0 → 全体的抑制（反射优先权）**：反射触发（危险信号过阈）时 R0 置抑制标志，
  R1 指令当拍被钳制到包络内；反射解除后按滞回释放。上层**无权关闭 R0**——
  这条不可逾越的优先级就是"越级抑制"；"释放"永远需要上层以新鲜参数重新证明
  （防抑制抖动用滞回，不用连击计数——连击是步数轴思维）。

### 3.4 健康与降级矩阵

| 失效 | 系统剩余能力 | 检测手段 | 恢复路径 |
|---|---|---|---|
| R2 死/超龄 | 探测、行为、反射全保留；归因冻结在最后置信；不学习 | R1 侧参数包龄期超 5 s + 心跳缺失 | R1 检测到 → 登记降级态；R2 重启后以新序列号重新证明，归因复核（挂 P1 修法②的复核思想到时间轴） |
| R1 死 | 反射维持安全姿态；世界继续演化（**时间继续流**——真"非我"证据的来源） | R0 侧 R1 心跳缺失 ≤3 拍 | R0 保持安全包络并告警；R1 重启后从 unknown 重新归因（复用现有重归因流程） |
| 模块死（现有 B5 语义） | 照旧 | 现有心跳超时 | 现有挂起/插回/换装流程，不改 |
| R0 死 | 系统终止 | 外层硬件/进程看门狗 | 全量重启（这是唯一允许"死"的层，因此必须最简单） |

设计纪律：**R0 的代码量与依赖面必须有硬上限**（例如：无 numpy 依赖、纯标量运算、
可逐行审计），因为它没有后备。

### 3.5 资源预算表（16GB RTX 3080 Laptop / D 盘 10.7GB 现实）

| 项 | 预算 | 理由 |
|---|---|---|
| R0 | 纯 CPU 单线程，<1% 核，<50 MB | 确定性优先；**永不碰 GPU**（CUDA 调度抖动不可审计） |
| R1 | CPU numpy，50 Hz × ≤8 ms ≈ 40% 单核；全环内存 <500 MB | 每模块向量 512×8B=4 KB；事件流/探测记录改**有界环形缓冲**（上限预注册）；f 反演只做增量式，禁止全量反演入 R1 |
| R2 | CPU 为主，GPU 可选（brain RNN 批量 rollout 预留 ≤4 GB 显存）；eigh/学习全在此环 | 笔记本热节流现实：R2 必须容忍被降速/暂停（这正是它"best-effort"定位的物理理由） |
| 消息队列 | 每队列有界（深度 64，溢出=丢最旧+登记） | 背压可见化，不许静默积压 |
| 磁盘 | 沿用 `runs\` Junction + 大 npz 用完即删纪律 | D 盘仅 ~10.7 GB（交接文档 §0） |

### 3.6 接入方式：改哪层、接哪层（对照章程 §4.3 要求）

- **不取代任何一层的认知内容，取代的是"它们相遇的方式"**：五层全部保留，
  但从"同进程函数调用网"改为"三环上的分布式进程"。
- R0/R1/R2 先以**同进程三线程 + 单调时钟服务**落地（诚实起点，见 §6 风险①），
  接口按"明日可拆成三进程"设计（队列 + 定时包，不用共享可变对象）。
- 分层落点：R2 跑 brain.step() 多步与全部学习；R1 跑 selfprobe 探测循环与
  归因状态机（时间窗版，见 §4）；R0 跑安全钳制与龄期巡检；world 侧独占一个时钟域。

## 4. 对现有资产的处置（逐层：保留 / 改造 / 推翻）

| 层 | 处置 | 具体动作 |
|---|---|---|
| **内核动力学** `brain.py` | **保留**，降环 | 整体搬入 R2。要求补两件工程合同：① `step()` 的 WCET 实测与预算登记；② `state()` 每次 192 样本抽 rng 且开销不小（INT G12）——限定只在检查点调用，写入使用规约。P1-P8 判据链不动，它们从此是"R2 环内部品质"，不再冒充全系统性质 |

## 5. 判据（可失败，含零假设/sham，沿用双集纪律）

全部判据跑 seed 0–5（判据集）+ seed 6–11（留出集）；凡涉及归因口径的以 §4 的
预注册换算为前提；**任何一条在任一集失败即如实登记失败**。

- **D1 · 节拍抖动判据**：三环各跑 T=120 s，记录实际周期序列。
  通过：R0 周期 1 ms，|Δt| ≤ 0.3 ms 的拍占比 ≥ 99%；R1 周期 20 ms，
  在 R2 满负载注入（eigh 风暴 + 全量反演风暴）下 |Δt| ≤ 8 ms 的拍占比退化 ≤ 5%。
  **零假设对照（使判据可失败）**：把同样的 R2 负载塞进 R1 同线程同优先级 ⇒
  R1 抖动显著劣化（预期退到不可通过）——若对照也能通过，说明测的分层是假的。
- **D2 · 降级存活判据（kill 矩阵）**：4 种单层失效（杀 R2 进程/杀 R1/拔模块/冻结 R2 输出）×
  双 seed 集。通过：杀 R2 后 R1 探测继续且 ≤3 拍内登记降级；杀 R1 后 R0 维持安全包络、
  世界时钟继续走、R1 重启后归因从 unknown 重新收敛；全程无未捕获异常、
  无校验失败、无 nan 泄漏（复用 INT 巡检项）。**Sham**：R2 空转但心跳正常（假活）
  ⇒ R1 必须凭龄期判降级；若 sham 被当作存活，判据失败。
- **D3 · 延迟注入判据**：世界-内核通路注入已知 τ_dl ∈ {0, 5, 20, 50 ms}。
  通过：① 带补偿的在线响应模型在 τ_dl ≤ 20 ms 时预测误差 ≤ 无延迟基线的 1.5×；
  ② 归因稳健性：self 模块加纯传输延迟不翻 world（自模型对自身延迟稳健），
  而"延迟随机化 sham"（响应时相与 CMD 解耦）必须翻 world——否则归因吃的是
  延迟巧合而非因果结构。**零假设**：无补偿基线在 τ_dl=20 ms 误差显著上升
  （证明补偿机制承重，而非系统碰巧迟钝）。
- **D4 · 时间窗归因判据**：P2 场景（事件稀疏，P(切换)=0.0025）在时间窗口径下，
  T=10 s 内事件型模块完成归因或给出 provisional 置信 ≥ 0.5。
  **对照组（已实证、使判据可失败）**：meeting10 探测数口径下 2000 步终态 unknown
  ——若时间口径在此场景仍 unknown 且无 provisional，判据失败。
- **D5 · 越级抑制判据**：注入危险信号触发 R0 反射，R1 指令在 ≤1 个 R0 拍内被钳制到
  安全包络，反射解除后按滞回释放且释放后 R1 无超包络输出。
  **Sham**：统计涨落（幅度低于触发阈的噪声）误触发率 ≤ 1%——若噪声也触发，
  说明"反射优先"实为"频闪误杀"。

## 6. 风险与不可行处（诚实清单）

1. **最大不可行：μs 级硬实时在当前软件栈不存在。** 16GB 笔记本 + Windows +
   Python（GIL）给出的是 ms 级调度抖动。本方案诚实起步 = **软实时三线程**：
   R0 名义 1 ms 实为"尽力而为 + 抖动统计验收"（D1 的阈值按实测校准后预注册）。
   真 μs 级反射环要等 R6 硬件（MCU/RTOS/实时 Linux）——判据 D1 现在测的是
   分层带来的相对改善，不冒充绝对硬实时。
2. **延迟结构升级会打破已登记的 S/W 组结果。** 世界改异步 + CMD 延迟生效后，
   W2/W6、S2/S3 的既有分数不可迁移；须按硬约束预注册、双集重跑、新旧口径并列，
   且 P1 类"宽度边界"问题要在时间口径下重新审计一遍（旧的 ma+1 论证是探测数轴的）。
3. **分层本身是新的 bug 源**：时钟域换算、消息乱序、龄期误判、队列溢出策略
   都可能引入 INT 式隐患清单的下一代。缓解：D2 的 kill 矩阵 + 校验字段
   （现有载荷哈希是好资产）+ 队列溢出必须登记不静默。
4. **归因变难是特性不是缺陷，但分数会难看。** 零延迟共谋被拆除后，
   S 组 30/30 大概率守不住——这是把"人设的容易"换成"物理的诚实"的必付学费。
   我明确主张：宁可分数退，不退物理结构；但这是所有者裁决项。
5. **与 E5 的划界风险**：降级切换瞬间的动力学稳定性（恢复是否经过不可返回区、
   滞回形状）是 E5 的吸引子领地；我只提供切换事件与日志接口，稳定性判据归 E5。
   若 E5 判"恢复路径不可保证"，R0 安全态必须升级为"可静态证明的不变式"——成本另计。
