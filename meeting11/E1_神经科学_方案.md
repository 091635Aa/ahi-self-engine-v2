## 0. 先回答所有者的提问：脑没有反向传播、没有全局损失、没有梯度，靠什么产生"自我/非我"与持续自主行为？

四件事，全部可计算、全部无梯度：

1. **闭环而非拟合**。自我/非我不是"算出来的表示"，是**控制回路的副产品**：运动指令同时发一份副本（corollary discharge / efference copy）到感觉通路做减法——自己发声引起的感觉被预测抵消，别人的不被抵消。蟋蟀的 corollary discharge 中间神经元在每次鸣叫前抑制自听通路，机制到细胞级明确 **[机制]**。
2. **双库分工而非单变量调慢**。时间尺度分离是**器官分工**：海马印迹 one-shot 写入、新皮层可塑性常数大若干量级、离线期重放把前者整合进后者（互补学习系统 CLS，McClelland/McNaughton/O'Reilly **[机制]**）。"自我在时间上的连续性"是**巩固的产物**，不是任何一个动力变量的统计性质。
3. **价态广播而非标量奖励**。多巴胺/去甲肾上腺素/乙酰胆碱/五羟色胺是**定性不同**的广播通道，各自门控不同可塑性参数（写入/学习率/增益/退缩——三因子规则 **[机制]**）。脑没有"一个数"，它有"几种状态"。
4. **viability 压力而非外部目标**。内感受误差（能量、体温、损伤）越出生理包络 ⇒ 强制优先级重排（注意捕获、行为切换、记忆偏向）；价态即内感受误差的符号与幅度（内感受推理框架，Seth/Friston **[类比]**——框架成熟、细节有争议）。持续自主行为由稳态 + 内生节律（睡眠压力）驱动，不靠损失函数。

AHI 现在用**统计拟合**去补这四件事的结构缺失。这就是"Transformer 式"病根在我的语言里的说法：不在于它有什么注意力，而在于它与分析式大模型共享同一个错误前提——**自我是一个待推断/待拟合的对象**。脑的答案相反：自我是被维持的（稳态）、被巩固的（记忆）、被回路的（corollary discharge），从来不是一个解。

### 1.2 五处展开

**① N1 的死因，在神经科学看是"必然"**。T5：换修仪器后 12/12 不可辨识（ρ̂₁(h_slow)=0.9973–1.000015）；T9：T=64000 下 h_slow 仍非平稳（ρ̂₁=0.9988–1.0037，收敛 0–1/12）⇒ "非平稳，不是窗口不足"；T10：多井势修好井内平稳，却暴露**占据构型游走**（τ~10³–10⁴）经 m 传导使 τ(h) 超出可辨识上限。三个都是同一错误的投影：**把时间尺度分离当作一个变量的属性去测量，而它在生物里是两个器官的分工**。生物解法不是把 h_slow 调得更慢，而是**把"慢"做成另一个库**：印迹痕迹几小时到几天，皮层统计数月到数年——比值由巩固律控制，可干预、可损毁、可证伪，永远不需要对它做 AR(1) 拟合。N1 应当**废弃**（所有者选项 B"判据重定义"的更进一步：换判据的**对象**，而非口径）。

**② 不动点自我 = 每步解方程**。生物递归回路 settle 到吸引子是存在的，但那是**动力学本身**，不是对目标变量的数值求解。`_self_model` 用 κ 保证不动点唯一、Anderson 加速收敛、`iters=12/tol=1e-4`——这是在把"自我"做成良定推断问题。后果已被 T 链记录：m3 无记忆不动点（根因四）⇒ τ(m3) 只能继承输入 τ（T8 Q4）⇒ A′ 补丁在近单位根输入下失效（T9 Q3-3）。**当一个自我模型的工程性质（唯一性、收敛性）成为首要设计约束时，它就不是自主体原理。**

**③ 标量 F 与动量是伪自评**。F 的三项聚合权重手定（w_self=6e3），mom=ΔF 去趋势动量把四种不同的"坏"压成一个数，再让 P1 校准头拟合这个数。ECE 在 12 seed 上反复摆动（C 落地退 3 改 3）不是校准问题——**被评对象本身类型错误**。调质通道不是把误差换个编码，而是把"下一步学什么（DA 写入 tag）/学多快（ACh）/调多警觉（NE）/退不退（5HT）"**分工**出去。

**④ q 的定性：不是 hypocrisy，是方向正确的退化形式**。受调节量+设定点+偏差进动力学——这是稳态的最小结构，P7 12/12 是真实资产，方向完全对。退化在三处：ζ 是"内部计算的统计"（‖h_i‖、std(g)、‖m‖ 的 EMA），不是**可耗竭的身体变量**——没有任何东西会因 q 失调而死；q* 随机游走漂移（ν~1e-4），无 viability 语义；偏差经随机 W_mq/W_gq 线性注入，无后果——生物的内感受误差是**价态**且**强制优先**（疼痛捕获注意、重排行为），不是加一项随机投影。

**⑤ 无海马脑**。全链路（brain/mbp/world/selfprobe/modality）没有任何事件级存储与巩固。P6 的"构成性自模型"建在 W_slow 临界游走+饱和的伪多稳上（T8：多稳真成分 7/12 + 单调漂移 2/12）；自我在时间上的连续性没有器官承担。生物海马损毁者仍能维持最小自我（q 层面），但失去"昨天的我"。**N1 想要的正是这个缺失的器官，却选了统计量这把尺子。**

**⑥ 归因不可修正**。INT P1（`meeting10/INT_问题清单.md`）：归因在探测 29 锁定后永不复核，d=16 误归因不可自愈。生物的归因是随巩固持续修正的先验。

### 1.3 此路为何不通（一句话）
T1–T10 已经实证撞墙：五轮规格、四种根因、12/12 不可辨识——每轮修补都把统计仪器推到极限，而不是把结构补出来。生物脑的对应教训写在损毁实验里：**没有哪个"自我性质"是靠在单变量上测统计量得到的**。

## 2. 核心主张

**一句话**：把"自我=拟合出来的表示"换成"自我=被维持、被巩固的过程"——快印迹库一次性写入带价态标签的事件，离线重放把它整合进慢统计库，四通道调质价态各自门控写入/学习/增益/退缩，内感受 viability 提供不可失败的自主压力；**自我/非我 = 慢库中动作条件统计对该路感觉的解释力；时间上的自我连续性 = 巩固律的产物**。

为什么天生全自主：
- 写入（novelty/价态触发）、重放（睡眠压力触发）、整合（巩固律）、遗忘（SHY+印迹退化）**全部内生触发**，无外部标注/奖励；
- 无全局损失、无梯度：可塑性 = 局部三因子规则，调质是广播不是优化信号；
- 唯一的"教师"是 viability 越界，它在系统内部定义；
- 时间尺度分离由**架构分工**保证：判据测的是两个库的内容漂移率之比——该量由构造有界、由巩固律可调。**N1 的病根被设计铲除，不是被修好。**

## 3. 机制：印迹-巩固自主内核（ECAE）

### 3.1 双库（取代 m / h_slow / 三层 m1m2m3）

**H（印迹库，海马式）[机制]**（CLS 为成熟计算框架；印迹分配竞争对应 CREB 兴奋性门控，Josselyn/Frankland）：

```
容量 M 槽位；事件 e_t = (z_t 摘要, a_t 动作, 结果摘要, tag v_t)
novelty_t = pe_t / (EMA(pe)+ε)          # pe_t = C 对本拍感觉的预测误差（相对自身基线）
v_t = DA_t − 5HT_t                       # 价态 = 好−威胁（见 3.2）

# 印迹竞争写入 [机制]
if novelty_t > θ_w or |v_t| > θ_v:
    i = argmin_i( |tag_i|·exp(−age_i/τ_H) )     # 挤掉最弱最老（竞争的工程形式）
    H[i] = (key=kwta(z_t,k), payload=e_t, tag=v_t, age=0)
age_i += 1  ∀i
# kwta：k-winner 稀疏化 = 齿状回模式分离的工程对应 [机制]
```

**C（皮层库，慢统计）[机制]**：沿用 `brain.py` 的 W 家族形态，但语义改为"只被巩固律更新的预测统计"：
- 在线几乎不学（ε_on 由 ACh 门控，基线≈0）；
- **动作条件子空间 C_act**：efference 预测器 ŝ=Ŵa 的后继（P8 资产落点）；
- **无条件子空间 C_free**：感觉流统计（novelty 的分母）。

**h_slow 的处置**：废除 ρ(W_slow)=1.9 正反馈环（`brain.py:146-148,645-647`）。慢语义由 C 的内容更新律承担——**库内容的平稳性由"权重只被巩固律改变"构造性保证**。T9 根因（β_slow·ρ=1.52 临界线性放大 ⇒ 盆地内也近单位根）与 T10 根因（占据构型游走）在新设计里**没有存在位置**：慢的东西不再是"临界游走的变量"，而是"更新受限的存储"。

### 3.2 价态四通道（取代 L 与标量 mom）[类比——分工边界有争议，V4 使其可证伪]

```
DA  = max(0, −Δpe_rel)     # 比预期好 → 门控写入 tag 强度、充当重放采样温度
NE  = CUSUM(pe 分布)        # 意外不确定性 → 抬增益、中断离线相（觉醒）
ACh = EMA(pe)               # 预期不确定性 → 门控在线学习率 ε_on
5HT = e_int                 # viability 负向 → 降 engagement、写负 tag
```
（DA=RPE、NE/ACh=意外/预期不确定，Yu & Dayan 框架。）**结构性质（判据盯这里）：四通道各门控不同参数，通道效应必须可分离——这是"不是标量"的可检验含义。** `WL` 线性混合废弃。

### 3.3 viability（q 的升级：从"读计算统计"到"有身体"）

```
受调节量 x = [节律违反度, H 占用率, sat（现有饱和度, brain.py:793）, ‖W‖ 增长]
包络 [lo,hi] 构造给定（viability 语义；q* 的随机游走漂移废除）
e_int = Σ max(0, lo−x) + max(0, x−hi)
e_int>0 ⇒ 5HT↑ + 注意捕获（gain 向纠偏方向重排）+ 负 tag；回稳 ⇒ DA 小信号
q 内核（τ_q/W_qq/ζ 机制, brain.py:240-270）保留为 x 的慢 readout
```
P7 的资产落在"维持行为"上：越界⇒重排，回稳⇒恢复。这是对"q 是否 hypocrisy"的最终回答：原结构对，缺的是**语义**（越界）与**后果**（强制优先）。

### 3.4 睡眠/离线重放（AHI 完全缺失的器官）[机制——系统巩固 + SHY]

```
睡眠压力 S ← S + novelty_t            # 每步累积（两过程模型的 process S / 腺苷 [类比]）
S > S_crit ⇒ 进入离线相；时长 R_r ∝ S；随后 S 清零
离线相（每步）:
    i ~ softmax((DA·v_i + ACh·novelty_i − age_i/τ_H)/T_DA)   # 系数由调质充当，非自由参数
    (z, a, z') = H[i].payload
    pe_r = C_act(a)(z) − z'
    C ← C − ε_off·(pe_r ⊗ pre)        # 单层内局部 delta 规则：误差与更新同突触局部可得
                                       #（小脑 climbing-fiber 结构 [机制]；无反向传播）
    W ← W·(W_target/‖W‖_row)          # SHY 乘性下采样 [机制]（Tononi–Cirelli）
    tag_i ← tag_i·(1−η_f)             # 巩固后印迹失独占，随后可清除（遗忘）
NE 突变 ⇒ 立即中断离线相（觉醒）
```
**系数去向是本方案的反调参承诺**：softmax 的系数全部由调质通道**充当**（DA=温度、ACh=β、age 项常数）。调质必须是那把尺子本身；若做不到，方案退化为"带生物学术语的调参"（§6 风险 1）。

## 5. 判据（5 条，可失败，双集+sham 纪律沿用）

> 全部按"若 X 机制存在，则扰动 Y 应导致 Z"格式；sham 必须**结构性**（禁"随机输入"式弱 sham）；
> 判据集 0–5 + 留出集 6–11 双集；先预注册后改码；不挑 seed；AUC 型一律带 sham 对照。

**V1 巩固传导**（生物学对照：定向记忆再激活 TMR [机制]）
- 若：离线重放存在且价态门控。
- 则：在线写入 K 个不同 tag 的事件，离线后 C 对**被重放事件**的预测误差下降显著大于未重放/被挤出事件（配对比较，双集）。
- sham：打乱 payload↔tag 配对 ⇒ 下降应消失或出现在错误事件上。
- 失败含义：C 的更新律没有被重放真正驱动——巩固是装饰。

**V2 突触稳态**（生物学对照：SHY 的清醒/睡眠突触尺度测量 [机制]）
- 若：乘性下采样存在。
- 则：长时运行后 ‖W‖ 有界、H 占用率回到带内。
- 对照：删除下采样 ⇒ 范数单调增长或饱和（两种失败模式均可测，非二选一豁免）。
- 失败含义：稳态是摆设，老 N2 病回归。

**V3 结构性时间尺度（N1 的替代判据）**
- 若：双库分工成立。
- 则：C 对固定探针集的响应漂移率 ≪ H 对同探针的漂移率，且比值随 ε_off 单调可调；干预 ε_off=0 ⇒ 比值→1。
- sham：用与 H 同更新律的"伪皮层"替换 C ⇒ 比值坍缩。
- 关键：测**内容漂移率之比**（有界量、可干预），不是单变量 τ 统计——不重蹈"向非平稳变量要统计量"。
- 生物学对照：慢波睡眠干扰实验——SWA 被干扰则巩固受损，慢振荡刺激则改善。

**V4 调质通道可分离性**（生物学对照：DA/NE/ACh 拮抗的药理双分离；[类比] 被此判据否证化）
- 若：四通道各门控不同参数。
- 则：单通道清零产生**通道特异**表型——DA⇒tag/重放选择失效而增益正常；ACh⇒ε_on 灵敏度失效而写入正常；NE⇒觉醒中断失效而学习正常；5HT⇒viability 反应失效而学习正常。
- sham：四份同一标量的拷贝 ⇒ 四种"损毁"表型应**不可区分**。双向可失败：若 sham 可区分则对照设计错；若真系统与 sham 同构则我的"非标量"主张为假。

**V5 viability 强制优先**（生物学对照：内感受误差→价态→注意与记忆偏向 [类比]）
- 若：viability 越界有强制优先级。
- 则：越界期间 (a) gain 向量向纠偏方向重排（方向性可测），(b) 紧随越界的印迹写入率上升（威胁性事件优先编码 [类比 flashbulb]）。
- sham：同幅度扰动打在包络内随机维度 ⇒ 无重排、无写入偏好。

## 6. 风险与不可行处（诚实）

1. **自由参数回归是最大风险**。§3.4 采样分布若留出自由系数（α/β/γ），全案退化为"带生物学术语的调参"。对策已内置（调质充当系数），但若 DA 信号太弱撑不起温度语义，此承诺要改——这是方案最可能死的第一处。
2. **CLS 双系统在 toy 规模太容易通过**：M=512 的小系统上 V1/V3 可能轻松成立 ⇒ 判据区分度存疑。对策：结构性 sham + 容量扫描（M∈{64,128,256,512}，V1 裕度应随 M 变紧，预注册单调容差）。
3. **BREAKING 面大**：m/三层/W_slow 的判据对象消失 ⇒ P1/P5/P6 全部重推导、锚点全重基线。这是诚实的代价，且方向正确：**"零锚点代价"恰恰是被所有者否定的方法论**——锚点安全不应是设计约束，机制正确才是。落地纪律不缺（T6 范式：原型→闸门→重基线）。
4. **归因低维退化可能复发**：INT P1 的 d>8 误归因在 T_rev 复核下或可自愈，但若 C_act 有效秩不足，复核也救不了——需增补"动作条件子空间有效秩下界"为前置判据。
5. **离线相与实时性冲突**（E4 领地，我只陈述需求）：巩固需要长时间低响应状态，生物解是 unihemispheric sleep + NE 觉醒中断；嵌入式对应物是否存在由 E4 质询（§7）。
6. **诚实分档总表**：CLS / SHY / corollary discharge / 三因子规则 / climbing-fiber 局部误差 = **[机制]**级（成熟理论、明确计算语义）；DA-NE-ACh-5HT 四通道的分工边界（DA 也编码 sensory prediction error 与 novelty，5-HT 的功能最杂）= **[类比]**，V4 正是让该类比可否证；viability 变量选取、θ_w/θ_v/S_crit/k 等阈值 = **[未实测]设计选择**。
