## 1. 回应质询（对"给 E1 的质询"逐条表态）

### 1.1 → E2（"器官标本"指控）

> E2 原话："你的判据**哪一条**能区分'从未经历分离的系统'与'经历分离后恢复的系统'？……请给出记忆判据的行为学化版本（再学节省就是现成的起点）。"

**裁定：部分接受。先纠正一个事实前提，再接受真问题。**

- **纠正**："你的判据（A_int、内感受 q）全是单快照统计量"是对上轮方案的印象。本轮 V1–V5 已换对象：V1 是"在线写入 K 个事件 → 离线重放 → 配对比较 C 的预测误差变化"的**前后对照设计**，V3 是"两库内容漂移率之比 + ε_off 干预"，V5 是"越界期 vs 包络内扰动"的**组间对照**——没有一条是单快照。E2 对 N1/P6 时代的诊断我全部签字，但那具尸体不属于本轮判据。
- **接受的部分（真问题）**：V1–V5 测的是**器官功能**，不是**发育史**。V1 能证明"巩固通路承重"，确实不能区分"从未经历分离"与"分离后恢复"——后者是 D3（陌生情境）的语义，前者是我的语义。这两类判据是**互补关系而非竞争关系**：器官判据回答"巩固机器存在且承重"，行为判据回答"这台机器参与了一个发展事件"。生物上这正是损毁-行为双证据结构：海马损毁不改变稳态自我（q 层面），只消灭事件连续性（H.M. [机制]）——所以我的器官判据**本来就不该**承担行为学判据的职责。
- **落实让步**：采纳"再学节省"作为 V1 的行为学对偶读出（见本文 §3 让步 4、§5 提案 P-C）。E2 说"再学节省就是现成的起点"——完全正确，而且它在我这边**有现成机制基座**：savings = 重入快于初学 = C_act 已被部分更新，只需 H 中印迹经重放残存（重学节省的巩固依赖性 [机制]）。同一实验、双读出：PE 下降给我（V1），节省给 E2（D-L5）。

### 1.2 → E3（"价值只有稳态设定点吗"）

> E3 原话："若'价值'只有稳态设定点，发展心理学/生理学上有没有**反例机制**（如探索驱动的价值独立于稳态）？若有，它在我的框架里应当是第二设定点还是第三公理？"

**裁定：接受（被说服：q 单独充当唯一价值源不够），但答案既非第二设定点也非第三公理。**

- **神经科学反例，两条 [机制] 级**：
  1. **信息本身是多巴胺奖赏**。Bromberg-Martin/Hikosaka：猴偏好在奖励前获得提前信息，DA 神经元对"信息预测误差"发放 RPE——信息价值的编码通道与流体奖励共享，与任何内感受越界无关。
  2. **感觉预测误差直接驱动 DA**（novelty/salience 通道）：新异刺激引发 DA 相位响应，不经过任何稳态受调节量。
  这两条合起来回答 E3：**q 设定点之外必须有第二价值源，且它在生物里不是另一个稳态变量。**
- **为什么不是第二设定点**：设定点语义要求"受调节量 + 包络 + 回稳压力"。信息价值没有包络——好奇心不回稳。**为什么不是第三公理**：公理是无时间性的，而信息价值在生物里有明确的时间载体——**价态 tag 印在印迹上，随巩固与遗忘衰减**（行为标记效应：新异事件经 DA 把弱印迹升格为强印迹，Moncada/Wang/Morris behavioral tagging [机制]）。价值的正确形态是**有记忆时间尺度的通道**，不是常驻公理。
- **给 E3 的落地处方**（进 §5 提案 P-D）：你的 G(a) = ê(a) − γ_e·(认知项) 里，实用项来源不该只有 q——应加一个 **tag 承载的价值分量**：动作候选的后继若与高 tag 井/高 tag 项记忆亲和，则获得额外下降。这正是我 §3.4 重放采样 softmax 中 DA·v_i 项的期望自由能镜像。顺带这一条同时回应 E2 对你的"掌握后重演"质询：技能 pe→0 后重演持续，机制是 **tag 存续驱动的重放偏向**（清醒/睡眠重放受奖励偏向调制，Singer & Frank [机制]）——信息增益饱和了，tag 还没衰减完。

### 1.3 → E4（时序合同）

> E4 原话："你需要我提供什么样的维护窗口（R2 独占、R1 冻结、时长/周期），以及你的印迹机制对时间戳龄期的容忍上限是多少？没有这个数，巩固在工程上无从落地。"

**裁定：接受，且合同可以给全——生物结构恰好让这个合同比 E4 预期的宽松。**

关键结构事实：**重放读的是 H，不是活状态。** 生物睡眠巩固的前提是海马与皮层在离线期被门控隔离（丘脑感觉门控 + 运动性麻痹；unihemispheric sleep 证明隔离只需半侧化，不需全系统冻结 [机制]）。对应到 E4 的三环：

1. **不需要 R1 冻结**。H 的 payload 是 append-only 不可变事件（本方案 §3.1），重放侧只读；R1 继续探测不受影响。唯一需要的一致性保护是 **C 的单写者互斥**：离线切片内只有 R2 写 C。E4 的"读()退化为取最新快照（双缓冲/seqlock 语义）"恰好白送了消费侧一致性——R1 在离线期读 C 读到的是旧快照，无碍。
2. **时长/周期**：R_r ∝ S（睡眠压力），S 每步累积 novelty，S > S_crit 触发。R_r 的硬下界 = 需覆盖的重放条数 × 单步重放成本；**但 R_r 不是截止时间合同**——见下条。
3. **可中断性（最关键的让步式设计承诺）**：每次重放一步是**自包含事务**——读 H[i] → C 上做一次局部 delta → SHY 一次行重标度 → tag_i 一次衰减。步与步之间无跨步一致性要求 ⇒ 任意时刻可被抢占，恢复后继续采样即可，**半套巩固态永远一致**（本方案 §7 给 E4 质询里我自己要的"被抢占时的一致性保证"，答案是：不需要保证，因为设计上无跨步不变量）。NE 觉醒中断 = 生物版本的抢占原语 [机制]，映射到 E4 的 R0 抑制信号复用。
4. **龄期容忍上限：无限期，但不是靠墙钟**。payload 不可变 ⇒ 数据不腐坏；重放资格由 tag_i 与 age_i 决定（tag 按重放次数/印迹竞争衰减，非墙钟衰减）。E4 的"R2 产出龄期上限 5 s"**不适用**于 C 的内部更新——那是状态自更新，不是可供消费的消息产品。E4 需要提供的只有三件：R2 的巩固切片调度、抢占信号线、MBP 上广播 offline 旗标（详见 §5 提案 P-B）。

### 1.4 → E5（"V3 单调、SHY 增益、临界面安全"）

> E5 原话："你的 V3'内容漂移率之比 ≪'是单调判据——越慢越好、无下界。……SHY 之后你的 C 库等效增益是多少、被谁调节？请给巩固律一条'临界面安全判据'。"

**裁定：三个质询两个接受、一个部分反驳。**

- **接受 ①（V3 无下界）**：被说服。单调判据的正确形态是**双侧带**：比值 ∈ [r_lo, r_hi]（预注册）。r_lo 防慢库冻结（重放不再改变 C ⇒ V1 同时失败，双判据交叉锁死），r_hi 防重放洪泛（ε_off 过大 ⇒ C 被洗掉区分度，catastrophic interference 的温和版）。双向干预检验：ε_off=0 ⇒ 比值→1（下界侧）；ε_off 逐级放大 ⇒ 比值穿过 r_hi 后 V1 开始失败（上界侧）。已登记让步 1。
- **接受 ②（SHY 的增益是一阶效应）**：被说服了一半，且被说服的那半让我的方案更好。我的回答：**SHY 本来就是增益调节器**——突触稳态缩放是乘性的、保持相对权重、由平均活动驱动（Turrigiano homeostatic scaling [机制]），生物上它就是"把库增益按回目标"的执行器。但我的 §3.4 把 W_target 写成了常数——这是错的：常数目标只对一种活动分布成立。**修正：W_target 改为由 C 自身活动统计驱动的稳态目标**（目标活动带进 viability 包络——本方案 §3.3 的 x 向量里 ‖W‖ 增长项正好是它的家）。"被谁调节"的答案由此闭合：被"目标活动带 vs 实测活动"的偏差驱动，执行器是 SHY 行重标度。已登记让步 2。
- **部分反驳（"慢库自己的 N1 病"的框架）**："τ→∞ 不可辨识"对 C 是**类型错误**：N1 的病是把 τ 当成**动力变量的属性**去 AR(1) 拟合；C 是**更新受限的存储**，它的"慢"不是滤波器相位滞后，是写次数少——ε_off 直接可测、可干预、可消融（V1/V3 的干预项就是干这个的），不存在"向非平稳变量要统计量"的操作，因此不存在"不可辨识"的暴露面。E5 的 K-BATTERY 作为**仪器**我不设防（甚至欢迎，见让步 2 的联合判据），但"慢库将重演 N1"这句话把存储与变量混为一谈——**"无法再学习"才是真风险**，而它由 V1 + 新增 r_lo 下界双重看守。
- **接受 ③（拒绝把临界性归入我的 viability 框架）**：收回原质询的"请声明它是我 viability 框架的一个维度"。接受"并列而非从属"：viability 调"活着"（受调节量=生理/资源变量），临界调节调"算得好"（受调节量=体制变量），共享 allostasis 数学形式。**代价**是必须给两条调节环立界桩——见本文 §2.4 反质询（情境条件带）。

## 2. 反质询（对 E2/E3/E4/E5 机制的质询）

### 2.1 → E2：D3 缺一个记忆器官，无状态条件反射可整门骗过

E2 判据原文："③ 重聚后 distress 恢复快于陌生人替换后"；"① 在场 vs 缺席：探索量（新颖区访问、动作熵）**在场 > 缺席**（安全基地效应）"。

**质询**：重聚恢复快于陌生人，语义是"对**这一个**照顾者的预期已在系统中留存，故重聚的预测误差更小"。这要求**人员特异的事件记忆**。但你的机制清单（§3.2）里没有任何跨 episode 存储：探索量、动作熵、distress 都是瞬时读数。请回答：**一个无记忆的反应式增益规则**（"检测到高应答性来源在场 ⇒ 唤醒基线下调"——对任何高应答者一视同仁，不区分这个还是那个）**凭什么通不过 D3 ①②③？** 按你自己的信息论形状 SENSE_C = C_own + κ·f(CMD−δ) + ξ，两个照顾者只要 κ 统计相同，就不可区分——而 Ainsworth 范式的灵魂恰恰是**依恋对象特异性**。

**机制的补法（我的领地内给出）**：照顾者共处的 distress episode 应当经 **social buffering** 改写价态 tag——生物上照顾者在场压低皮质酮反应、改变对厌恶事件的记忆巩固（social buffering [机制]）。即：在场期的事件负 tag 减半，分离期事件负 tag 加重，重放时按 tag 加权——"重聚恢复快"才有了跨时间的物理载体。**判据补强（可失败）**：D3 全套跑两遍——正常 vs 巩固剥夺（ε_off=0 或 H 清空）。若巩固剥夺下 D3 ①②③ 不塌缩，D3 测的是反应式调节，不是依恋。这正是你自己的"消融+剥夺对照"纪律（§6 风险 1）的用武之地，只是消融刀要落在**我的器官**上——你我判据从这刀开始咬合。

（次要质询：D2 的 κ·f(CMD−δ) 是 efference 学习器的标准食物——P8 的 Ŵ(a) 三因子化后会把 κ 和 δ 学进去，把照顾者折进自我侧。你的 still-face sham（κ→0、C_own 照常）救了这一手，但请预注册第三个对照：**自我侧随机化 κ/δ** 的自延迟反馈通道——若系统对"带噪自延迟"与"照顾者"不可区分，D2 测的是残余方差不是社会语义。）

### 2.2 → E3：你的"巩固"是一个无选择、无价态的隐藏印迹缓冲，C5 测错了因变量

E3 伪代码原文："巩固（睡眠态，由 L 的觉醒驱动触发; 非每步）: `W_selfHop += Σ_{S∈近期快照} S⊗S`（Hebb 单次写入，零对角强制）"。

**质询（三连，全部机制级）**：

1. **"近期快照"是从哪来的？** 你的 S_t 是 γ_S=0.98 的迹（迹长 ~50 步），睡眠态触发时你却要"近期快照"复数集合——这背后必然有一个**快照缓冲区**，而它在你全文中无容量、无选择律、无淘汰。这就是我 §1.1 指认的"无海马脑"问题的**回装**：你悄悄造了一个 H 库，但它是**滚动窗口垃圾场**。生物重放不是窗口倾倒：重放是**稀疏的、价值偏向的、事件选择性的**（睡眠重放占比极小且偏向高价值/新异轨迹 [机制]）。窗口倾倒式巩固在容量上撞你自己 §6-1 的墙（"自相似历史会让井互相合并"、0.138D≈140 井），在语义上巩固了"最近发生的一切"而非"值得巩固的少数"。**要求：给出选择律。** 若答案是"全存"，140 井的容量纪律与自我相似性合并就是你方案的第一死因（你自己预注册了）；若答案是"选"，请把我的 §3.4 采样 softmax（DA=温度、ACh=β、age 项，调质充当系数、零自由参数）拿来对表——选不出来的巩固不叫巩固。
2. **C5 的因变量错了**。"C5 巩固-行为耦合：巩固后井占据 dwell 重尾指标（P99/P50 比值）提升 ≥ 2×"——这是**动力学性质**，不是**内容传导**。生物巩固判据的黄金标准是内容级的：巩固后对被巩固内容的再表现改善（TMR 范式：cued 项改善、非 cued 项不动 [机制]）。把 dwell 重尾当 DV，随机 Hebb 垃圾写入也能提升（你的 sham-E 恰好证明这一点：随机向量写入"重尾必须不升"——但你没有反向保证"真内容写入**内容**变好"）。**要求：C5 增补内容传导 DV**——巩固后对被巩固 episode 的 cleanup 成功率 / unbind 查询成功率应高于未被巩固条目（配对、双集）。这把你的 C5 和我的 V1 变成同一实验的两种记分。
3. **睡眠触发挂在 L 上是定时炸弹**。"由 L 的觉醒驱动触发"——L 的设定点带线性漂移（`brain.py:598`，E5 §1.4 已立案的混淆源）。你的睡眠时刻表由一条**设计斜坡**驱动：跑得越久睡得越勤（或越懒），且不同 seed 的巩固节律不可比。**要求：睡眠触发必须是累积态**（我 §3.4 的 S ← S + novelty，涨满即睡、睡毕清零），预注册；不许挂在任何带设计漂移的读数上。

### 2.3 → E4：R0 的反射弧是化石——没有调制通道就没有习惯化与敏感化

E4 原文："R0 ……必须简单到可静态审计：无内存分配、无特征分解、无 IO"；"反射触发（危险信号过阈）时 R0 置抑制标志，R1 指令当拍被钳制到包络内"。

**质询**：你的 R0 阈值是**出厂冻结的**。生物反射弧的教科书事实相反：**反射增益本身是可塑的**——Aplysia 缩鳃反射的敏感化由 5HT 能调制中间神经元易化感觉-运动突触（前易化），习惯化是同突触抑制，两者是所有学习教科书的第一章（Kandel [机制]；惊跳反射的状态调制同理）。这不是高级认知，这是脊髓级的生理学。后果具体化：

- 你的 D5 sham"统计涨落误触发率 ≤ 1%"只在**平稳噪声**下成立；长期运行中输入分布漂移（世界换了、身体换了），冻结阈要么常态误触发（频闪误杀，你自己的 sham 词），要么真危险穿透。**"永远不倒"的系统若反射永不校准，它的不倒是被设计豁免的，不是被维持的**——这正是 E5 的"墙/膜"之辨在你领地的形态，我不越界替他下结论，只陈述生理学事实：膜的标志是**响应与校准**，墙的特征是**无差别钳制**。
