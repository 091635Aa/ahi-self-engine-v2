## 2. 六层定稿

### L1 底座（执行层 · 署名 E4）

**机制**
- 三时钟域执行栈 + world 域 + caregiver 域 + 持久层（第四构件）：定时包四字段（时钟域/单调时间戳/龄期上限/传输延迟）、单写者纪律、读无副作用（快照/seqlock）、维护窗口仲裁器、三态龄期语义（`调节中` 标志——到期只降置信不回退、写者心跳死才回退）、ack 背压、R0 钳制通知（anti-windup 双路全堵）（S2/S10）。
- 越级抑制六条（E4 R3 §3.2）：① R0 自有原始安全通道（B5：预注册标量集 {限位界、速度界、资源界}，初版 ≤8 个标量，world 直供、R1/R2 无写权、R0 纯标量比较）；② 钳制（反射触发 ⇒ R1 指令当拍钳入收紧包络）；③ 广播与反 windup（R2 调节律收钳制通知 ⇒ I_c 冻结）；④ 滞回释放（释放阈=触发阈×0.8）；⑤ 重证明（须新鲜 R2→R1 门控参数包，否则常态包络+默认门控）；⑥ 反射调制通道（B7：校准量出厂值一倍程内移动、默认冻结、单写者=R2）。
- kill 矩阵 6 演练行 × 双 seed 集 + 2 sham 行（K-A 杀 R2 / K-B 杀 R1 / K-C 拔模块 / K-D 冻结 R2 输出=假活本体 / K-E 离线窗超时 / K-F NE 通道死（睡死）+ S-1 假活 sham / S-2 噪声误触发 sham）；排程纪律：演练带标记、恢复静默窗=T_rec、干预间最小静默、演练窗与 K 观测窗互斥、演练期不计入发育史（E2 签）。
- A1 口径：**锁死面**（接口冻结：MBP 包九字段语义+载荷哈希+单调序列号+降级包+B9 档案；定时包四字段/`调节中`/ack/钳制通知/offline 旗标/演练标记字段/caregiver 域延迟留白字段；各模块方法签名）+ **白名单**（运行模型五处 W1 步进废除/W2 读去副作用/W3 字符串→数值字段/W4 心跳自喂+R0 巡检/W5 裸 list→有界环形缓冲）+ **四道闸**（预注册先于改码/--realtime 惰性启用 canonical 逐行对照（关闭时 diff=0）/双集回归不挑 seed/W1–W5 即全部永不隐性扩充）。
- A9 两件（E4 R3 让步）：延迟留白（caregiver 域延迟字段对系统侧置 NULL+噪声化开关）；包络经验驱动扩张通道（D 门触发 widening，硬上限=出厂包络×2，扩张后稳定性判据归 E5）。

### L2 治理（监督层 · 署名 E5）

**机制**
- G-Layer v2 = C-HOME（体制调节）+ B-MAP（边界测绘）+ K-BATTERY（无标度仪器）；只输出信号不接管机制；**前置链（硬性）**：K5 六情形自证 ≥90%（含 G，G3 ≥85%）→ σ̂/β̂ 偏差标定表（A11）→ 时滞注入标定（k_p/η_i 初值）→ 任何 K 组引擎测量与 K3；前置不过 ⇒ 守门层整体不进场。
- **C-HOME v2（A4 落地：情境门控双带双积分器）**：ctx ∈ {wake, offline} = ACh 电平阈值化 ⊕ offline 旗标双源一致性（E1 判别信号：ACh_t/median_wake(ACh) < 0.5 持续 ≥100 R2 拍 ⇒ offline-like，失配 >500 R2 拍 ⇒ 账本结构事件；E5：两源冲突 ⇒ context_ambiguous ⇒ 调节冻结至消歧）；每 R_reg 步分域观测（不跨域混合样本，域切换即断窗重开）；wake 调节带（驱动执行器）/offline 监测带（I_c 冻结、β 保持、越带只报警走 post_shy_audit 通道）；切换协议：I_c 快照入账本、回同域从快照续（不清零）、切换后首拍只观测不写 β（一拍守门）+ E1 β 过渡斜坡 ≤20 R2 拍；预注册开关 offline_steering ∈ {observe_only【默认】, active_band}——默认值待 E1/E5 消歧（§5-3）。
- **B-MAP**：候选集 v2 = 14 变量 {h_slow, q, g, m, β_slow, L, W_selfHop, C‖W‖, DA, NE, ACh, 5HT, H占用率, sat}（覆盖 E1 补齐组，viability 经 sat 入集）；逐变量扰动→补偿测试（run0 分位带 +2σ【有界量在 logit 域】、T_rec^fast 判读、消融对照=静默候选补偿通道）；未过者记"声明变量"不进 SCC——viability 不许靠声明存活。
- **K-BATTERY 六情形**：A–D 合成情形 + **G 打洞序列**（G1 周期短洞 ρ_hole∈{5%,20%} / G2 演练长洞 ~T_rec^slow 量级 / G3 长洞+边界跳变 |Δu|>5σ_run0）；验收 G1/G2 ≥90%、G3 ≥85%；洞容忍度：观测窗洞占比 ≤10% 且无 G3 跳变 ⇒ 作数窗，否则记"洞暴露"单列报告；洞日志双源供给（E4 演练标记 + world 跳变检测器）；无洞日志的序列一律 ⊥ 不得过 K1/K2。
- **账本纪律器官**（与 C4 机器审计合并）：环形 4096 条、溢出丢最旧+计数登记、写入率遥测伴生（突增 ⇒ 自动触发 K1 三窗漂移复核）；{γ_H, γ_S, λ_M, η 尺度, θ_w, ε_f, C, 压平份额阈值} 变更=账本条目；K3 验账（k_c=0 时账本增量必须为 0）。
