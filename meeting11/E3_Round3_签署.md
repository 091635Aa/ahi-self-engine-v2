### 1.2 C2b / W-HOME——判据式（S9 条款的落地文本，伪代码级）

R2 文本"min_k |cos(S, IM[k])| > θ_w 才写"在正式判据中**消歧**为下式的 max 形式
（意图是防井合并：与任何既有井重叠过高即不写）。K5 自证先行（S3）、判读协议用 E5 §1.3
原文不改一字（S9）。

```
# ═══ C2（盆内，原文保留）+ C2b（井间补集）合并判据 ═══
# 常量全部先验预注册，不扫参；变更=账本结构事件（S12）
D = 1024
θ_w      = 预注册    # 新颖性门阈（S 与任一井的最大重叠上限）
ε_f      = 预注册    # 反主导压平步长
θ_share  = 预注册    # 反主导触发份额
T_obs ∈ {4K, 8K, 16K, 32K, 64K}          # 五窗，FSS 跨窗塌缩为通过形态之一
IM 指派  = 构造期预注册固定               # E5 §1.3 条款：保证 k*(t) 跨窗可定义

# ── W-HOME 写入控制（R2 维护窗口内执行；前置=巩固许可门）──
def 巩固(S_snapshots, regime_ok, offline_band_ok):
    if not (regime_ok and offline_band_ok):        # E5 §5.3-1 许可门，本席签署（前提=A4 双带，§1.3）
        账本登记(e_c, "带外拒绝写入"); return
    for S in S_snapshots:
        if max_k |cos(S, IM[k])| ≥ θ_w: continue   # 规则1 新颖性门：防井合并（原案 §6-1 死法的结构阻断）
        S_perp = sign(S − Σ_k cos(S, IM[k])·IM[k]) # VSA Gram-Schmidt 去相关后取号
        W_selfHop += S_perp ⊗ S_perp（零对角强制）  # Hebb 单次写入
    for k where dwell(k) > θ_share·T_obs and tag(k) < median(tag):
        W_selfHop −= ε_f·(IM[k]⊗IM[k] − I)         # 规则2 反主导压平（价态排序：只压低 tag 井）；
                                                   #   减 I 保零对角、保对称 ⇒ 1982 Lyapunov 性质不丢
    if |井集合| > 0.1·D:                           # 规则3 容量驱逐（0.138D 定理容量的 72% 裕度）
        删 重叠最小优先、同分取 |tag| 最小 的井      # E1 价态进驱逐排序，非温度 softmax，零新自由参数

# ── C2b 判读协议（对占据链与 S_t 低频各跑 K-BATTERY）──
def C2b_判据():
    k*(t) = argmax_k cos(S̃_C(t), IM[k])            # 占据链 = 库内容量类判据对象（S1 合规）
    R_occ = K-BATTERY(k*(t) 驻留序列, T_obs)        # K2 仪器：CSN 似然比 + bootstrap
    R_S   = K-BATTERY(S_t 低频分量（PC1、‖ΔS_t‖）, T_obs)   # K1 仪器：DFA α̂ + FSS 塌缩
    # 通过形态二选一，必须声明体制：
    PASS_P_i:  R_occ 判驻留指数 且 dwell 均值 ≤ τ_s 上界（T/8）且跨 seed 可分辨
               ⇒ 过，声明"亚稳体制"；E5 按 S9 公开撤回补集要求，C2 维持原文
    PASS_P_ii: R_occ 判幂律（R·√n > 2）且 R_S 判 α̂∈[0.85,1.15] 跨 ≥1.5 十进位 + 跨窗塌缩
               ⇒ 过，声明"临界游走"；井间补集条款长期生效
    FAIL（唯一禁带 = T10 死带）: 驻留指数 且 dwell 均值 ~ 观测窗同量级（>T/8）且跨 seed 不可分辨
    # 消融 sham（结构性）：切除规则1+规则2 重跑 ⇒ 禁带必须出现；不出现 ⇒ C2b 对写入规则不敏感，判据作废
    # 仪器灵敏度 sham（E5 §1.3 原文）：随机向量井 / γ→0 退化井 ⇒ battery 必须归类 A（无游走）
```

两点声明：(a) S_t 低频判读声明为**自我状态载体的体制量**（它同时是 E5 K4 候选被调节量与
本席查询基板），不是裸动力变量；若所有者裁 S_t 不合格，C2b 退守 k*(t) 单通道（占据链=
库内容量，E1 坚持 5 的口径内无争议）。(b) 本席交付 W_selfHop 进 K4 候选集（可失败形式：
B-MAP 测不出 W_selfHop 进被调节集 ⇒ W-HOME 是假的，R2 让步 1 原文维持）。
