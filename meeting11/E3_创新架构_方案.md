> 身份锚定：替代计算范式的数学与先例（预测编码/自由能机器、储层计算、Hopfield/能量模型、
> 超维计算 VSA、脉冲网络、神经符号、主动推理）。**全文无任何注意力/Transformer/梯度预训练思路。**

## 1. 诊断：当前 AHI 哪里仍是"Transformer 式"的

所有者判定的病根——"用统计修补堆叠，而非第一性自主体原理"——在 `brain.py` 里不是隐喻，
是逐行可指认的。我按** epistemology（认识论）**而非字面架构来判：凡"从数据里拟合出一个头、
再用留出集验收"的方法论，就是 Transformer 思维，与矩阵叫什么名字无关。

### 1.1 最小二乘读出 + median-split 标签（最硬的证据）

`train_readouts()`（L724–741）：`np.linalg.lstsq(Sd, G, rcond=1e-3)` 训练图式读出 `Ws_out`；
置信度头 `Wconf` 用 `y = (F[1:] < np.median(F))`（L736）——**自己给自己造了训练集和分类标签**，
再跑 train/holdout 验 ECE。这正是"无外部标注"承诺的破口：标签虽产自内部，**方法**却是
监督学习范式（拟合→留出验收）。L666 的 `conf = σ(Wconf @ m)` 是这个头的推理期形态。
`_efference()`（L391–395）同病：`S_eff/B_eff` 累积 + `np.linalg.inv` 解 π 加权岭回归——
一个**每步在线重解的批量最小二乘**，本质是把"自我/非我判别"外包给一个拟合出来的 Ŵ。

### 1.2 EMA 统计量当"自我"的内容

`self_err_ema`（L662）、`dF_ema`/`dF_abs_ema`/`mom`（L684–690，"我最近在变好还是变差"
= ΔF 去趋势滑动统计）、`zeta_ema`（L405–415）、`aro_ema/aro_dev`（L457–461）、
`r_ema_eff`（L387–388）。自我模型的基座 `base`（L546–550）= 五个**手调权重**的通道线性混合：
`w_fwd`、`w_surp`、`w_mom`、`w_slow`、内感受 `W_mq q`，外加软归一 cap。
去饱和修复（L64–66 注释）自曝了方法学：`w_mom 9.0e4 → 10.0` 是**为了通过判据而调出来的数**。
"自我"在这里不是一个结构，是一组窗口统计量的加权混合——判据不过就调权重，
调不动就加层（三层 m1/m2/m3，L189–197）、加注入点（N4 在归一化**之后**注入，L555–556
注释原话："若在归一化之前注入……效应量塌到 0.039/0.024"）——**架构被测量口径反向塑形**，
这是拟合范式的标准死法。

### 1.3 h_slow：想"调出"多稳，而不是"构造"出多稳（N1 的制造者）

`W_slow` 谱半径 1.9 × `β_slow` 0.8 = 1.52（L145–148）——多稳来自**临界随机放大 + tanh 饱和**。
T9 已定案：盆地内等效小信号增益 ≳1 ⇒ 盆内也近单位根，`τ(h_slow)` 64K 窗仍不收敛
（`.trae/specs/close-ahi22-r0/tasks.md` T9）。T10 的多井势补丁又死于"占据构型游走"。
根子：**性质应当被构造进结构，而不是从随机矩阵的统计里调出来**。临界游走的"慢"
不是记忆的慢，是随机的慢——它当然可以进判据集，也当然会在留出集翻车。

### 1.4 P5 的"自由能"只是手加权的标量

L675：`F = complexity + pred_err + w_self·self_err_ema`——三项是三个不同量纲的统计量
拼起来的标量，`w_self=6e3` 是手调尺度。这不是主动推理的生成模型，
是"给 F 这个名字找了个可计算的代理"。交接文档自己也承认这是"只算 F 标量的形式"。

### 1.5 为什么此路不通（一句话版）

这条路的验收逻辑是"调参数→统计过线→留出集复核"，而全自主系统要求**每一个量都是结构自己
长出来的**。T1–T10 十步诊断的全部痛苦（τ 有偏→不可辨识→不适定→多井又游走）都是
在"用拟合范式逼近一个非拟合对象"时产生的**范式税**。税收到了第五层还没收完。

## 2. 核心主张

**一句话**：把"自我"从统计量改成**代数结构**——自我 = 超维向量空间（VSA）里一个可查询的
角色-填充复合向量，其慢动力学是**存有自己历史的高维能量地形上的吸引子弛豫**；行为由
**动作条件化关联记忆上的期望自由能**选出；全部可塑性是**局部 Hebbian / 误差门控写入**，
系统里不存在 lstsq、EMA 混合、手调通道权重、也不存在任何全局梯度。

**为什么它天生全自主**（逐条对应"无外部标注/无奖励/无梯度训练集"）：
- **无标注**：唯一的"误差"是 e_t = 1 − cos(x_t, x̂_t)——自己上一拍预测与这一拍感知的
  余弦差，有界于 [0,2]，由自身生成模型产生。学习规则只用 (pre, post, e) 三个局部量。
- **无奖励**：行为偏好只有一个内生来源——稳态设定点（现有 `q` 内感受内核与 `L` 核团的
  setpoint，受调节量而非拟合参数），以 homeostatic 项进入期望自由能。
- **无训练集**：关联记忆 M 与自我井阵 W_selfHop 的写入是**单次/逐步外积**，
  没有样本、没有 epoch、没有留出集；"泛化"由高维准正交性承担，不靠拟合。

每一步都在做感知-预测-行动闭环（§3 伪代码第 1–6 步），不存在"先训练后推理"的两阶段。

## 3. 机制：VSA-主动推理自主机（工作名 HDC-AIF）

### 3.0 设计原则（三条公理）

1. **储层公理**（储层计算）："读出可以廉价，储备池必须物理"——快速区域动力学
   `A_i/Wc/Bin/gating`（L89–96、L649–656，谱半径 0.92·0.9 已收缩）**原样保留**，
   它是物理，不是拟合对象；所有可塑性搬到它外面的记忆结构里。
2. **代数公理**（VSA/HDC）：表征是 D=1024 的双极超维向量，三种运算——
   绑定 ⊛（逐元素乘）、叠加 +（求和后取号）、置换 ρ（循环移位）；
   相似度 = 余弦。"自我是什么"的每个问题都答成一次 unbind+cleanup（代数操作），
   不答成一次回归。
3. **能量公理**（Hopfield/主动推理）：慢自我动力学是对称 Hebbian 关联矩阵上的能量下降；
   井=自己存进去的历史，盆内收缩由构造保证（对称阵、零对角 ⇒ 能量是 Lyapunov 函数）
   ——**T9 处方①（盆内 Hessian ≻ 0、小信号增益 <1）在这里不是调参目标，是定理**。

### 3.1 状态与常量

```
D = 1024                          # 超维维度（16GB 显存下 numpy 逐步外积无压力；未实测）
γ_H=0.9, γ_S=0.98, λ_M=0.999      # 三个衰减常数（先验给出，不调参；判据见 §5）
角色向量（固定随机、预注册种子）: R_act, R_q, R_body, R_err, R_g, R_mod[i]
项记忆 IM: {键 hypervector → 清洗模式}（内容寻址，容量守卫见 §6）
M   : D×D 关联记忆（动作条件化预测）
W_selfHop : D×D 对称、零对角（自我井阵）
```

固定随机投影 `Φ_fixed: R^d→{±1}^D`（不学习——储层公理；modality 的"已知投影器"
思路在 MBP 里本来就有，`mbp.py` L39 `已知投影器`）。

### 3.2 每步伪代码（感知-预测-行动闭环）

```
输入: u_t ← world 经 MBP（接口不动）; 候选动作集 A（world 动作通道的 K 个预注册基方向）

1) 感知编码:   x_t = sign(Φ_fixed @ u_t)                       # 双极 hypervector，不学
2) 上下文迹:   H_t = γ_H · ρ(H_{t-1}) + x_t                    # 全息历史迹（Plate HRR trace）
3) 预测:       x̂_t = cleanup( M @ (a_{t-1} ⊛ H_{t-1}) )        # 动作条件化关联记忆读出
4) 误差:       e_t = 1 − cos(x_t, x̂_t) ∈ [0,2]                 # 预测编码 delta，有界
5) 局部学习:   M ← λ_M·M + η(e_t) · x_t ⊗ (a_{t-1} ⊛ H_{t-1})   # 外积写入；η(e)=η₀·min(e,1)
                                                              # 惊讶门控：预测准时不写（防记忆糊化）
6) 行动:       ∀a∈A:  x̂_a = cleanup(M @ (a ⊛ H_t))
               G(a) = ê(a) − γ_e · (1 − cos(x̂_a, x̂_default))    # 期望自由能 = 实用项 + 认知项
               a* = argmin G(a)  → 经 MBP CMD 包发给 world
7) 自我全息:   S_t = γ_S·ρ(S_{t-1})
                     + (q_t ⊛ R_q) + (a* ⊛ R_act) + (Φ_body ⊛ R_body) + (e_t ⊛ R_err)
               # Φ_body = Σ_modules (RESP_i ⊛ ID_i) —— MBP 的模块ID天然就是角色向量（B2 描述符复用）
               # 查询即代数: "我刚才做了什么" = cleanup(unbind(S_t, R_act))；
               #            "我此刻感受如何"   = cleanup(unbind(S_t, R_q))
8) 慢自我弛豫: S̃_0 = S_t;  S̃_{c+1} = sign(W_selfHop @ S̃_c)，c=1..C   # C≈5 次能量下降
               自我输出 = S̃_C；当前井 k* = argmax_k cos(S̃_C, IM[k])；
               井深证据 E(S̃) = −½ S̃ᵀ W_selfHop S̃（有界，逐维归一后 |E|≤D/2）
9) 巩固（睡眠态，由 L 的觉醒驱动触发; 非每步）:
               W_selfHop += Σ_{S∈近期快照} S⊗S（Hebb 单次写入，零对角强制）
               容量守卫: 井数 > 0.1D 时删 cos 重叠最小的井（Hopfield 容量 ~0.138D，见 §6 风险）
```

注意 5) 与 6) 的关系：**学习只在惊讶时写、行动永远先问记忆**——这就是"发育中的自主机"
最小闭环，每一步都同时是推理步和（可能的）学习步，两阶段消失。

## 5. 判据（可失败，含 sham；全部有界量，判据集+留出集双集）

- **C1 代数承重（N3 精神）**：完整系统自我探测 AUC ≥ 0.95（双集）；**sham-A**：把全部角色向量
  换成同一随机向量的随机置换（破坏代数、保持统计量分布）⇒ AUC 必须塌到 ≤0.7。
  过不了 sham 即"代数没承重，是余弦统计在过线"。
- **C2 盆内平稳（N1 的有界替身）**：井弛豫能量斜率均值 < −c₀（收缩证据），且井内序列
  `ρ̂₁ + 2·SE < 1` 于 12/12（用现行 `tau_fit_detail` 守卫，仪器沿用）；**sham-B**：W_selfHop
  存随机向量（非自己历史）⇒ 多稳性与井深判据必须失败。此判据替换 N1，属口径变更。
- **C3 反事实行动**：`sim(x_{t+1}, x̂|a*) − max_{a≠a*} sim(x_{t+1}, x̂|a)` 在判据集显著 > 0
  （配对检验，双集）；**sham-C**：M 的键中抹掉 a（动作不进键）⇒ 该量必须塌到 0。
  证明期望自由能真的在按"动作改变世界"选动作，而非挑了随机恒动作。
- **C4 端到端无拟合自主**：全程代码审计口径下，闭环路径上 **lstsq/inv/EMA 手调混合权重
  出现次数 = 0**（这是结构判据，可机器检查），且 R3 的 S1–S5 语义（重归因/换装/档案）
  在反事实归因信号下双集通过；sham-D：归因信号换成常数 0.5 ⇒ S 组必败。
- **C5 巩固-行为耦合**：巩固后井占据 dwell 重尾指标（P99/P50 比值）提升 ≥ 2×，且 C1 不退化；
  **sham-E**：巩固时写入等量随机向量 ⇒ 重尾必须不升。证明"井=自己的历史"而非"井=占位符"。

全部判据沿用：不许挑 seed、不可辨识不计通过、AUC 型必须带 sham、先 `_CHANGELOG` 预注册。

## 6. 风险与不可行处（诚实清单）

1. **VSA 容量与串扰**（最大死法）：双极 HDC 的迹深度与项记忆容量有限（Hopfield 容量
   ~0.138D ⇒ D=1024 约 140 井，**自相似历史会让井互相合并**）。若自我快照彼此余弦 > 0.9，
   多稳性资产可能消失——C2 的 sham-B 会如实暴露。缓解：存复合去相关（VSA 版 Gram-Schmidt），
   **未实测**。
2. **η(e) 门控是新的"手调超参"风险**：γ_H/γ_S/λ_M/η₀ 虽声明为先验不调，但如果判据过不了
   就会有人想调它们——必须事先写死"只许换结构、不许扫参"的纪律条款，否则本方案重蹈覆辙。
3. **判据不可通约**：P1-ECE 类"校准"判据在无拟合系统中语义改变（置信变成有界代数量）；
