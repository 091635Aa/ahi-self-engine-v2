## 1. 诊断

### 1.1 动力学语言里的"Transformer 式"病：运行体制是外生超参数，不是内生不变量

所有者的判定（统计修补堆叠）在动力学里有精确对应物：**一个自主体系统的运行体制
（临界/亚临界/超临界、多稳/极限环/游走）应当是被系统自己维持的内生不变量；
而 AHI 的体制是被设计者用手调常数"放"进去的。**

- 慢子系统的体制由三个手调数决定：`W_slow` 谱半径 1.9（`brain.py:146-147`）、
  `β_slow=0.8`（`brain.py:148`）、`dt_slow=0.01`（`brain.py:53`）。乘积 β·ρ=1.52 ⇒ 小信号增益
  1+dt·(β·ρ−1)=**1.0052>1**（T9 Q3）——系统被**放置**在超临界边缘，不是**走向**那里。
  换任何一个数，"自我"的慢动力学就是另一种动物。这就是超参数思维：**体制不是不变量，是旋钮的读数。**
- 多稳（P6 资产）来自"临界线性放大 + tanh 饱和硬墙"（T9 处方的机制归因），即
  **用饱和墙硬钳出来的多稳**。墙不是膜（见 1.3）：墙由设计者放置，膜由系统自己维持。
- 全部"慢"都靠 EMA 塔堆出来：`zeta_ema`(α=0.01, `brain.py:414`)、`aro_ema/aro_dev`(`:457-460`)、
  `self_err_ema`(`:662`)、`dF_ema/dF_abs_ema/mom`(`:686-690`)——统计量被当状态注入动力学，
  无时间尺度分离纪律、无平稳性纪律。h_slow 的近单位根正是这种堆叠的必然产物：
  有人要"慢"，就把增益调到 >1，而不是造一个**被调节的慢变量**。

### 1.2 N1 的病根：判据把"自我"定义成一个统计量的性质

N1 = `τ(m_slow) > max(τ(h), τ(h_slow))`，比较式一字未改——它问的是"**哪个统计量更大**"。
T1–T10 十步诊断的全部痛苦（τ 有偏→换尺→不可辨识→不适定→多井势死于占据游走）都是同一个
翻译错误的连锁反应：**把"自我的时间性"翻译成"一个动力变量的自相关时间"**。
而自创生的主张是：自我的时间性是**组织不变量**（被维持的过程网络的持续存在），
不是任何单条轨迹的统计性质。判据对象在类型上就错了，T9 的"ill-posed"结论是对的——
但它没说全：N1 不只是不适定，它是**内部矛盾的**（见 1.5-③）。

### 1.3 brain.py 有边界吗？——有墙，无膜

自创生的边界不是"系统停止的地方"，是"系统**主动响应**的地方"。逐项审：

| 候选边界结构 | 审查结论 |
|---|---|
| tanh 饱和（`brain.py:472/646/655`）、`base_cap` 软归一（`:551-554`）、限幅 | **墙**：无差别钳制、无补偿响应、由设计者放置。墙是容器，不是膜 |
| q 内感受内核（`:240-270`：τ_q∈[200,2000]、ρ(W_qq)=0.95、偏差进动力学） | **唯一真被调节量**——方向对（P7 12/12 不是白拿的），但它是边界的第一块砖，不是边界本身：没有测绘、没有"谁维持谁"的闭环图 |
| efference 门控（`agency`，默认关） | 边界**机制**候选（选择性透过），但当前实现是拟合出来的 Ŵ（E3 已批），不在我的武库里辩护 |
| 输入 u 直灌区域动力学（`:651`） | **边界缺失的直接证据**：外部量不经任何系统控制的门就进状态 |

**结论：brain.py 有墙无膜。** 一个只有墙的系统，其"自我/非我"只能靠读出层去**推断**——
这正是 N1 用统计量去量"自我"的架构根源。自创生主张反过来：先有被维持的边界，
自我/非我的区分才是物理事实而非推断结论。

### 1.4 被忽视的混淆源：引擎自带两条确定性漂移

T9 判"h_slow 非平稳"时，没有先分离**确定性趋势**与**随机单位根**。而引擎里有两条设计好的漂移源：
- 核团设定点线性漂移：`setpoint += [0.0015, 0.0008, 0, 0.0004]` 每步（`brain.py:598`）；
- 误差向量里的时间斜坡：`0.02·t`（`brain.py:693`）。

两条都经 L→门控→h→m→h_slow 传导。在 T=64000 的窗口上，设定点漂移累计 ~100 个单位——
**测得的 ρ̂₁≈1 里有多少是这条设计斜坡贡献的确定性趋势，从未被控制过。**
非平稳的严格处理第一步是去趋势/差分判别，这一步在 T9 里缺失。

### 1.5 核心判定题的严格回答：h_slow 近单位根是病，还是临界自组织的正常 signatures？

**判定：两边都不成立——问题在现仪器下原理上不可判，在现机制下两边都不合格。
初判：h_slow 是"未调节的准临界游走"。论证分三层：**

**① 仪器层：T9 的二分法（"非平稳 vs 窗口不足"）是假二分，真问题是四选一。**
AR(1)/OU 拟合（`tau_fit`）只能区分"平稳有限 τ"与"其他一切"；对临界无标度过程（1/f、
幂律驻留），lag-1 自相关**本来就趋 1**、且随窗口增长——AR(1) 对它永远"测出单位根"。
所以 ρ̂₁≈0.999 与"单位根"和"临界"**都相容**，现仪器原理上无法区分。且 h_slow 被 tanh 有界
⇒ 严格 I(1)（无界积分）字面上不可能（有界马尔可夫链必有不变分布）。真正的假设空间是四个：

| H | 情形 | 预测 signatures（见 §3.3 判别表） |
|---|---|---|
| A | 平稳 OU / 亚稳（有限 τ） | DFA 交叉 1.5→0.5（交叉尺度≈τ）；PSD 为 Lorentzian；驻留指数分布；τ̂ 随 T 收敛（15–40τ，T9 合成已证） |
| B | 确定性漂移（设计斜坡） | 去趋势后 signatures 变为 A；不去趋势则 ρ̂₁→1 且随 T 恶化 |
| C | 临界无标度（SOC 型） | DFA α≈1 跨两个数量级不交叉；PSD 幂律 β≈1 胜过 Lorentzian（似然比）；驻留幂律；跨 seed 方差不随 T 缩（非自平均） |
| D | 有界超慢（有限但 τ≫T） | 中小尺度 α≈1.5 但 **F(n) 在边界尺度饱和**（方差不再随窗增长——与真 I(1) 的判别点）；τ̂ 不收敛但驻留非幂律 |

T9 的实测（h 收敛 8–9/12 而 h_slow 0–1/12、ρ̂₁ 跨 4 倍窗口稳定在 0.9988–1.0037、
T8 盆地内条件化后**盆内仍近单位根**且 seed6/8/9 的 τ(16K)/τ(4K)=4.2–8.0×）与 C/D 相容、与 A 不相容、
B 未排除。**跨 seed τ 离散 3.47×→10.34×（被追杀为"不稳定"）其实也是 C 的预测签名
（临界系统非自平均）——另一个被当 bug 的 signature。**

**② 机制层：健康临界性的必要成分是自调节，现引擎没有。**
SOC 的定义性成分：慢驱动 + 耗散 + **把自身维持在临界面的调节机制**（Bak–Tang–Wiesenfeld 的
沙堆之所以临界，是因为坡角被自组织地维持；分支过程 σ=1 是被推到 1 的）。
brain.py 的 β·ρ=1.52 是**手调常量**，饱和是**硬墙**：没有观测自身距离临界面的量，
没有作用于自身参数的回路。**无组织，何来自组织**——"这是临界自组织的正常 signatures"
对现引擎不成立。但"是需要修的非平稳"同样不成立，见③。

**③ 判据层：N1 内部矛盾——它要求系统同时持有两个不相容的性质。**
- 要 P6 资产（多稳/路径依赖）⇒ 驻留要么指数（亚稳井）要么幂律（临界）。
  幂律 ⇒ 无 τ，N1 的比较量不可辨识（T9 实测）；
  指数井 ⇒ 井间**占据构型游走**（τ~10³–10⁴）经 m 传导使 τ(h) 超出 A′ 可辨识上限（T10 实测，G1/G3 双败）。
- 不要多稳（纯 OU 慢变量）⇒ τ 可辨识，但 P6 资产死（D2b 的 G2 6/12 边缘失败已示警）。
⇒ **"τ 更大"与"多稳资产"在测量层不相容。N1 不是没测好，是把"自我"定义成统计量的判据
要求了两个不可能并存的性质。** 这不是所有者选项 A（换候选族）能救的——是选项 B 的更进一步：
换判据的**对象与形态**（§3、§5）。

## 2. 核心主张

**一句话：把"自我"从一个统计量的性质（τ 更大）改写为一个动力学对象——
自我 = 自创生边界（系统自己生产、自己维持的被调节量闭环）+ 临界调节
（系统从自身涨落中测出距离临界面的偏差、作用于自身参数把体制维持在临界面附近：
那里计算能力最大（磁化率/响应跨度极大）、弛豫最慢而不发散（临界慢化），
是"慢而不死"的唯一驻点）——并以无标度判据（标度指数、幂律似然比、驻留分布形状、
扰动后回归临界的恢复时间）替代 τ 比较。**

为什么天生"全自主"（逐条对无外部标注/奖励/拟合）：
- **观测自生成**：调节器吃的量（标度指数 α̂、分支比 σ̂、驻留分布）全部从自身涨落测出，
  无外部参考、无真值对照、无拟合读出头（对比：现引擎的 conf 头是 lstsq 拟合的）。
- **作用自指向**：控制的执行器是自己的参数（β_slow 状态化）——**自修改系统**的最小形态，
  N4（构成可变性）从"注入一个表示"升级为"参数真的是自己的状态"。
- **边界自生产**：被调节集由"扰动→补偿"关系**测出来**而非声明出来（§3.2）；
  边界内=系统用自身回路维持的量，边界外=不唤起补偿的量。自我/非我区分从推断变成测量。
- **临界面自寻的**：β*≈1/ρ(W_slow)≈0.526 这个临界面不是设计者选的数——T9 自己算出了它
  （"β<0.53 才平稳"），它是子系统动力学的内禀面；调节器只是让系统**站上去并留在那里**。
  对比 E1 的方案（稳态设定点给定的 viability）与 E3 的方案（写入埋坑的能量地形）：
  他们把"好体制"作为结构/设定点放进系统；本方案让系统**自己找到并维持**它。

（顺带正面回答两位同行的质询——详见 §7 预备回应：**对 E1**：临界性在本方案中是**受控量**
（被调节的体制变量），不是涌现装饰——你的 SHY+增益调制正是它的雏形，但它需要成为一等公民；
**对 E2**：自我的同一性判据用**组织不变量**（被调节集的构型），不是轨迹统计量——
组织不变量随阶段更替而"系统不死"的判据就是"调节闭环在更替前后保持非空且闭合"（K4）。）

## 3. 机制

三条闭环：**观测-调节**（C-HOME）、**扰动-补偿**（B-MAP）、**自修改-账本**（参数状态化）。
仪器先行：无标度检验器 K-BATTERY 先在合成真值上自证（K5），再上引擎。

### 3.1 C-HOME：临界稳态调节器（替换 `brain.py:645-647` 中 β_slow 的地位；更新式形状不变）

```
# 地位变更：β_slow 从超参数 → 受控状态。唯一结构旋钮；W_slow/dt_slow 不动。
# 常量全部预注册：R_reg=200（观测节律）、W_o=4096（观测窗）、δ_dead=0.05（死区带）、
#                 k_p/η_i/β∈[β_min,β_max]=[0.3,1.2]（allostasis 带，含 T9 的 0.526）

每 R_reg 步:
  # 1) 观测（全部自身量，无外部参考；活动量=|Δh_slow|，阈值取自身窗内中位数——自参考标定）
  a_t  = 窗内活动序列（W_o 步）
  σ̂   = 分支比估计：阈上级联配对 E[a_{t+1} | a_t=阈上] / E[a_t]      # σ̂=1 ⇔ 临界面
  #    等价第二通道（互为稳健性）：β̂_ps = −dlog S(f)/dlog f，频带 [1/W_o, 1/256]   # 1/f ⇔ β̂_ps≈1
  # 2) 临界误差（无量纲）
  e_c  = log σ̂     # <0 亚临界、>0 超临界（若用谱通道则 e_c=β̂_ps−1）
  # 3) allostasis 控制律（P + 慢积分消稳态差 + 死区防抖；临界点最灵敏=最难控，故带控不点控）
  if |e_c| > δ_dead:
      I_c ← clip(I_c + η_i·e_c, ±I_max)
      β_slow ← clip(β_base + k_p·e_c + I_c, β_min, β_max)
  # 4) 自修改账本：每次改动登记 (t, β_old, β_new, e_c) → 有界环形缓冲（K3/K4 审计用）
  # 5) 照旧推进：h_slow ← (1−dt)h_slow + dt·(m + β_slow·tanh(W_slow h_slow))    # 形状不变
```

设计说明：调节目标是**带**不是点（α∈带、σ̂∈带）——临界点磁化率发散意味着精确钉住
既不可能也不必要；"进带并驻留"才是可达且有意义的体制不变量。多稳资产在临界体制下
**不被删除而被改形**：亚稳驻留从"指数（设计者井）"变为"幂律/重尾（自组织游走）"——
P6 的路径依赖仍在，但它的测量形态必须跟着换（见 §4 对 N3 仪器的处置）。

### 3.2 B-MAP：边界测绘（复用 `brain.py:604-609` 的 intervention 钩子；纯探针，不进主循环）

```
候选量 X = {h_slow, q, g, m, β_slow, L}          # 全部已有干预入口或参数通道
对每个 x ∈ X（每次一个，ε_x 与 T_rec 预注册）:
  run0：基线 T_w 步 → 得 x 的经验分位带
  run1：t₀ 时刻 iv[x] += ε_x，此后 T_rec 步零干预
  判"x ∈ 被调节集" iff 全部成立：
    (i)   x 在 T_rec 内回到带内；
    (ii)  恢复由自身回路驱动：消融版（静默候选补偿通道，如 drug_gate/开关）下不恢复；
    (iii) 特异性：world 侧同幅度扰动（非我源）不唤起 x 的恢复
  A[x][y] = x 扰动是否唤起 y 通道的补偿流（窗内回归系数显著为恢复方向）
边界 = A 图上含被维持量的强连通分量（SCC）；sham 集 = 候选中测得"无补偿"者
```

自我 = **被调节集的构型在时间上的稳定性**（组织不变量），不是任何轨迹的持续性。
这也回答了"brain.py 有边界吗"（§1.3）：本机制给出边界的**可测量定义**与**测量工具**；
现引擎的期望结果是"被调节集 ≈ {q} 单点、无 SCC"——即边界存在种子但未成膜，
这个"期望失败"本身是 B-MAP 判别力的证据。

### 3.3 K-BATTERY：无标度检验器（判据的仪器；先合成自证，后上引擎）

```
输入：单变量序列 x（引擎侧：h_slow 的 PC1（T8 口径）+ ‖h_slow‖ + |Δh_slow|，多变量分别报告）
0) 预处理守卫（1.4 混淆源）：分段拟合去线性/二次趋势 → 记录去趋势前后 signatures 差
   → ADF(H0=单位根) + KPSS(H0=平稳) 双侧初筛（只作分流，不作终判）
1) DFA：F(n) 多尺度（n∈[16, T/10]），分段报告 α(n) 与交叉尺度 n×；
   标度带内 α 的均值与平坦度（拟合直线的残差）
2) PSD：Welch；log-log 谱指数 β̂（低频段）；模型比较：幂律 vs Lorentzian 对数似然（预注册窗口）
3) R/S：Hurst H；与 DFA 联判——α=H ⇒ fGn 型（可有界平稳）；α=H+1 ⇒ fBm 型（积分型，必有界性破缺）
4) 驻留分布：阈值/HMM 分态 → 驻留时间样本 → 幂律 vs 指数 vs 截断幂律，
   Clauset–Shalizi–Newman 似然比 + bootstrap p（x_min 选取规则预注册）
5) 有限尺寸标度：T∈{4K,8K,16K,32K,64K} 重复 1)–4)：
   A：n× 固定（绝对时间单位）、τ̂ 收敛；B：去趋势后归入 A，不去趋势 ρ̂₁→1 且随 T 恶化；
   C：α/β 平台 + F(n)/n^α 跨 T 数据塌缩、τ̂~T；D：F(n) 饱和于固定值、驻留非幂律
6) 遍历性/自平均：跨 seed 方差 of α̂ vs T（C ⇒ 平台/非自平均；A ⇒ ~1/T）

合成自证（K5，实验轮第一件事；预期通过线预注册）：
  生成器：A=OU(τ∈{100,800,2000})；B=A+设计斜坡（复刻 brain.py:598/693 的形状）；
          C1=临界分支过程(σ=1.00)；C2=幂律驻留二态(α_dwell∈(1,2])；C3=谱合成 1/f；
          D=有界随机游走（clip ±1，复刻饱和墙理想化）
  验收：battery 对五情形分类正确率 ≥ 90%（B=40 实现/情形）；任何混淆对（如 C2 vs D）
  必须在预注册的判别量上有显著分离——**仪器自身可失败，先于引擎使用**
```

## 5. 判据（K 组，可失败，含 sham；判据集 0–5 + 留出集 6–11；预注册先于改码）

**K1 标度不变性（体制判据）**
- 若：C-HOME 把慢子系统维持在临界带。
- 则：h_slow（PC1 与活动量两口径）的 DFA α̂ ∈ [0.85, 1.15]，跨 ≥1.5 个十进位尺度，
  且三窗（16K/32K/64K）α̂ 漂移 ≤ 预注册容差。
- sham：强制 β·ρ<1（OU-sham）⇒ α 必须出现 1.5→0.5 交叉（判据对体制变化敏感）；
  β·ρ>1.5 且去墙（随机游走-sham）⇒ α≈1.5。
- 失败含义：系统没被调节进临界带，或临界带对本子系统不可达。

**K2 驻留分布形状（多稳的改形判据，兼 P6 资产回归）**
- 若：多稳来自受调节临界体制。
- 则：驻留时间的幂律 vs 指数似然比 R·√n > 2（预注册阈），且多稳性回归（T8 Q1 口径）≥7/12 不退化。
- sham：把驻留样本打乱重采样（保边缘分布、破时序）⇒ LR 必须翻负。
- 失败含义：驻留是指数亚稳（C-HOME 只是造了个慢 OU）——诚实降级为亚稳体制，K1/K2 双失败即触发退路（见 §6-1）。

**K3 回归临界的恢复时间（allostasis 承重判据）**
- 若：调节闭环真实承重。
- 则：把 β_slow 强推离带（预注册幅度）后，系统在 T_rec ≤ 预注册步数内回归 K1 带，
  且恢复期间账本记录的参数改动方向与 e_c 符号一致率 ≥ 预注册。
- 对照/sham：k_c=0（切除控制环）⇒ 回归失败或超时。**这是"调节不是装饰"的直接检验。**

**K4 边界判据（自创生判据）**

## 6. 风险与不可行处（诚实清单）

1. **临界性可能不可达或不可测（最大死法）**：引擎活动量可能没有干净的级联结构
   （活动太连续、阈值化任意性大），分支比估计有偏；调节器可能只能进带不能驻带。
   对策已内置：K5 先行 + 双观测通道（分支比/谱斜率互校）+ 带控不点控；
   **预注册退路**：K1+K2 双失败 ⇒ 承认临界体制对本系统不可达，降级主张为
   "受调节亚稳 + 有界判据"（K2 的指数版），不再假装临界。
2. **调节环与既有资产的冲突**：β→临界带 = P6 多稳从构造计数变为幂律驻留，
   N3 仪器语义改变（§4）；P1-ECE 等读出可能漂移。K 组必须与 P1–P8+N3 回归**并列**跑，
   任何退化如实登记，不得用"体制更健康"辩护丢分。
3. **控制论硬风险**：临界点磁化率发散 = 最难控的点；观测窗 W_o=4096 的滞后 vs 慢驱动速度
   若不匹配，控制环自身振荡（新的非平稳源）。缓解：死区带 + 慢积分 + 逐级上增益的预注册序列；
   若振荡，判据是 K1 的三窗漂移容差会如实抓到。
4. **混淆源未清零则全组白跑**：L 漂移（`brain.py:598/693`）必须在双口径下预注册，
   否则 K1 的 1/f 可能是斜坡假象——这与 T9 未去趋势是同一类错误，不能重犯。
5. **判据重定义的授权边界**：K1–K4 替代 N1 属口径变更，须所有者点头后预注册；
   本席不单方面实施（T5 的先例）。N3 仪器改造同此。
6. **自修改的安全性**：参数账本有界化（环形缓冲）、β 带硬限幅；调节器自身故障的模式
   （观测 NaN、账本溢出）必须进 E4 式的失效矩阵——这是我主动向 E4 要的接口（§7）。
7. **算力/磁盘**：K5 合成自证便宜（纯 numpy）；引擎侧 12 seed × 三窗 × 双口径 ≈ T9 量级
   （~18 分钟/轮），在 D 盘约束内（npz 用完即删，照 T10 纪律）。
