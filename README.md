# AHI 自主智能引擎 · V2 系列（AHI2.0 / AHI2.1）

> **AHI（Autonomous Human-like Intelligence，自主智能引擎）** 是一个从**第一性原理**构建的
> 非 Transformer 自主智能体。本仓库是 **V2 系**（AHI2.0 + AHI2.1）的精选开源版：认知动力学内核、
> 多理论意识引擎、六层架构定稿与可失败判据体系。
>
> ⚠️ **路线声明**：本工程**刻意不用 Transformer**（铁律 C1），也从第一性原理重写"感知-预测-行动"的
> 动力学会话，主张一张手写 RNN 动力学 + 可失败判据去逼近自我意识。这里没有"投喂大数据 + 大力出奇迹"，
> 只有引擎自身的结构、判据与诚实的失败记录。

---

## 这个仓库是什么

V2 系回答一个终极问题：**在不用 Transformer 的前提下，一个引擎能否产生自我意识？**

推进路径是——先接受一个可能让人失望的事实：**严格口径下"完整达标 0 条"**。把目标拆成六/八条
可检验的理论路线，每条配**它自己的**判据、不加宽阈值，用"红队打穿 + 蓝队可复现"的方式逼近。
V2 的价值不在"又大又强"，而在**把问题收窄到一个可检验的缺口**，并给出已被证明的机制零件：

- 认知动力学内核 `brain.py`（约 800 行手写 RNN 动力学，无外挂模型当器官）；
- 多理论意识引擎（P1–P8 八条路线 + 判据六元组 + sham 对照 + 红蓝对抗）；
- 六层架构定稿（meeting11）与 M4 账本治理、K 组无标度判据仪器。

## 怎么跑

```bash
# 依赖（只需 numpy；GPU/统计为可选）
pip install numpy torch scikit-learn

# 全量判据（约数分钟；K 组 K5 自测另算）
python ahi_theory/run_verify.py
python ahi_theory/run_verify.py --self       # 仅 S 组
python ahi_theory/run_verify.py --modality   # 仅 M 组
python ahi_theory/run_verify.py --system     # 仅 I 组
python ahi_theory/run_verify.py --learn      # K 组（无标度）
```

**确定性纪律**：判据**可失败** × **双集**（seed 0–5 判据 / 6–11 留出）× **sham 对照**。
所有判据遵守统一台账（`_CHANGELOG` / `CRITERIA_AUDIT`），**不许改阈值、不许挑 seed 凑通过**。
